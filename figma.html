Figma AI 設計轉代碼與設計系統

透過自然語言直接連通全球第一的協同設計平台 Figma。Antigravity AI Agent 能精確解析畫布上的 Frame 樹狀結構、Auto Layout 約束與樣式 Token，一鍵產生符合專案現有元件庫的 React、Vue 或 Tailwind CSS 生產級程式碼，徹底實現「設計即代碼 (Design-to-Code)」。

1. 功能概述與生態架構

在傳統開發流程中，工程師需對照 Figma Dev Mode 逐一手工測量 Padding、手動複製色碼與 CSS 屬性。Antigravity 的 Figma 擴充功能將整個設計檢驗與代碼生成流水線自動化：

原生 Design-to-Code

自動將 Auto-Layout 映射為 Flexbox/Grid，將字型與色彩樣式映射為 Tailwind CSS 或 CSS Variables，產出乾淨無冗贅的結構。

Code Connect 雙向映射

不只生成通用 HTML，更能識別 Figma 中的按鈕、下拉清單變體 (Variants)，直接對應引用您專案中既有的現成 UI 元件。

畫布批註與雙向協作

AI 能直接讀取設計師與 PM 留下的 Comments 批註，甚至在畫布指定座標自動建立標註回報：「該按鈕已在 PR #42 實裝完畢」。

2. 這個功能能做什麼？

畫布節點深度解析 (Node Tree Inspection)

只需給予一個 Figma 節點 URL（如 `?node-id=123:456`），AI 自動提取該 Frame 的內距 (Padding)、間距 (Gap)、圓角 (Border-Radius)、投影 (Box-Shadow) 與響應式約束。

Design Tokens 與 Variables 自動同步

自動萃取設計師定義在 Figma 中的色票集合與尺寸 Token，生成可直接在專案中引用的 `tailwind.config.js` 或 CSS 根變數。

SVG 圖示與點陣圖素材自動切圖匯出

無需手動逐一點擊圖示匯出。AI 自動遍歷指定圖標頁面 (Icons Page)，批次將所有向量圖標匯出為精簡優化的 SVG 檔案並存入專案資料夾。

Design QA 像素級驗收對比

比對前端實際渲染的 DOM 結構與 Figma 設計稿，標記出文字大小落差、未對齊的間距或未匹配的色彩 Hex，協助設計團隊快速完成驗收。

3. 核心 MCP 工具架構與 API

MCP 工具名稱 核心參數 回傳型態 功能說明與最佳實務
figma_get_file file_key, depth Document Tree 讀取檔案整體層次結構，建議指定 depth=2 以免大檔案傳輸超時
figma_get_node file_key, node_id Node Properties 取得特定 Frame 或 Component 的幾何座標、Auto Layout 與填充屬性
figma_export_images file_key, node_ids, format, scale Image URL Map 將多個節點批次渲染匯出為 SVG、PNG、JPG 或 PDF 下載網址
figma_get_comments file_key Comments Array 檢索檔案中的所有批註、回覆串與位置座標，供 AI 萃取需求變更
figma_post_comment file_key, message, client_meta Comment Object 在畫布指定座標點建立新留言，通知設計師實裝進度或提問確認

5. Design-to-Code 四大工程守則

守則一：尊重 Auto Layout，拒絕絕對定位 (Absolute)

高質感的代碼轉換必須依據 Figma Auto Layout 轉化為 Flex/Grid 流式佈局，絕不使用硬編碼的 `absolute top-[123px] left-[45px]`，以確保跨螢幕尺寸自適應。

守則二：優先複用已有元件 (Component Reuse)

AI 生成代碼時，會先掃描專案既有的 UI Library（如 Button, Input, Modal, Badge），避免產生數十個樣式重複的孤兒小標籤。

守則三：字型與色彩必須 Token 化

嚴禁在代碼中隨意留下無註解的十六進位色碼（如 `#7C3AED`）。應一律對齊至專案 Tailwind 語意顏色（如 `bg-brand-600`）或 CSS 變數。

守則四：Depth 限制防爆記憶體

大型 Figma 專案動輒包含數萬個節點。調用 `figma_get_file` 時務必傳遞合理的 `depth` 參數，或直接指定具體的 `node-id` 進行局部精確獲取。

6. 安裝與 Figma 存取憑證設定

7. 常見問題與除錯指南 (FAQ)

Q1: 為什麼提取設計時只拿到空白 Frame 或 403 Forbidden？

請確認您產生的 Figma Token 具備該檔案所屬團隊或組織的「檢視 (Can View)」或「編輯」權限。若是私有企業團隊檔案，需確認 Token 具備 File Read 權限範圍。

Q2: 如何快速找到特定元件的 node-id？

在 Figma 桌面版或網頁版中，點選任何一個 Frame 或圖層，瀏覽器網址列最後就會出現 `?node-id=123-456`（或者冒號 `123:456`），直接將整串 URL 貼給 Antigravity 即可！

Q3: 遇到設計師沒有使用 Auto Layout 的畫布該怎麼處理？

Antigravity 內建視覺幾何推理引擎，即使設計師使用的是自由拖曳圖層，AI 會根據各圖層的座標與相對空間間隔，智慧推論出最合理的 Flexbox 與 Grid 排版結構，避免生成脆弱的絕對定位代碼。
