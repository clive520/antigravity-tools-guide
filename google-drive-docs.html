Google Drive & Docs

開發者：Google Workspace Official

"Read, search, draft, and edit documents directly in Google Docs; manage, upload, download, and share files across Google Drive seamlessly."

在 Antigravity 的 AI 工作流中，**Google Drive & Docs** 是所有知識處理的樞紐。Google Drive 負責整個雲端空間的智慧檢索、下載讀檔、上傳備份與共享權限管理；而 Google Docs 則賦予 AI 直接起草長篇文章、教案、規格書、研發紀錄與結構化排版編輯的能力。兩者搭配，徹底擺脫手動複製貼上的繁瑣作業。

2. 這個功能能做什麼？（核心能力架構）

雲端硬碟全內文深層搜尋

不僅能搜尋檔名，AI 還能根據檔案類型（PDF、Docs、試算表）與關鍵字進行全文檢索，快速定位散落在各目錄中的重要參考資料。

自動起草排版 Google Docs

直接在使用者指定的雲端目錄中建立結構化的新文件，自動套用大標題（H1/H2）、段落、粗體重點、項目清單與結論摘要。

現有文件智慧修訂與批註追加

讀取現有 Docs 內容並在指定段落後方追加章節、更新版本紀錄、替換過期內容或進行文法與錯別字批改潤飾。

多團隊協作與權限分享管理

AI 完成文件起草後，可自動產生共用連結、指派特定同事的檢視（Viewer）或編輯（Editor）權限，並即時回傳文件線上網址。

跨文件資料彙整與知識庫提煉

一次讀取多份 Drive 中的 PDF 論文、會議紀錄或參考手冊，由 AI 融會貫通後提煉出核心綜述，輸出為統一的報告文件。

本機檔案同步備份至雲端

本機產生的 Markdown 筆記、匯出圖表或專案代碼封裝檔，可藉由 Drive 擴充功能一鍵安全同步上傳至 Google 雲端保存。

3. 支援的核心 MCP 工具對照表

Google Workspace 官方擴充套件向 Antigravity 註冊的底層能力清單：

外掛來源 底層 MCP 工具名稱 功能作用與典型參數
Google Drive gdrive_search 搜尋檔案與資料夾，支援名稱比對、mimeType 過濾與全文檢索
Google Drive gdrive_download / read 讀取並下載雲端檔案內容（PDF、純文字、匯出 Docs 內文）
Google Drive gdrive_upload 上傳本機檔案至指定雲端資料夾，支援設定 MIME 格式
Google Drive gdrive_share 設定共用權限（reader / writer / commenter）並產出共用網址
Google Docs gdocs_read 解析指定 documentId 的完整章節、大綱與文字結構
Google Docs gdocs_draft / create 新建空白或帶排版的文件，設定標題並寫入首批章節
Google Docs gdocs_edit 針對既有文件插入段落、替換文字、追加表格與更新樣式

4. 我該如何使用？（10 大跨角色實戰 Prompt Playbook）

日常辦公到深度研發

不管是老師備課、工程師寫規格、行銷做內容或法務審合約，複製以下範本即可直接在對話中呼叫 AI 執行：

範例 01 · 教師 / 教育工作者

單元備課教案自動起草與學生學習單產出

工具: gdrive_search, gdocs_draft

痛點情境：需要參考雲端硬碟中的「108 課綱自然領域綱要」，為國小五年級設計水溶液實驗的三節課教案並產生學生學習單。

> 「請搜尋我 Google Drive 裡的『自然科課綱草案.pdf』，研讀水溶液酸鹼性相關指標，在我的『教學備課』資料夾中建立一份名為『五年級水溶液探索教案與學習單』的 Google Docs。內容須包含教學目標、3 節課的探究活動設計、安全注意事項，以及附帶兩題思考題的學習單格式，完成後給我編輯連結。」
預期效益：AI 幾十秒內自動完成課綱比對並產出排版工整的教學文件，節省 1~2 小時手工編寫時間。
範例 02 · 文史與學術研究員

田野調查筆記彙整與地方文史研究論文初稿

工具: gdrive_download, gdocs_draft

痛點情境：硬碟裡有多份田野訪談錄音摘要、清代文獻記載與廟宇碑文抄錄，需要彙集成完整文史報告。

> 「請搜尋我的 Drive 中『沙鹿地方文史』資料夾內的所有筆記，比對三塊厝與保安宮的歷史沿革，起草一份名為『沙鹿三鹿里文史與信仰變遷研究』的 Google 文件。包含引言、歷史地理背景、信仰中心考證、現代社會意涵與參考文獻，並自動加上小標題與引用註腳。」
預期效益：自動穿針引線將分散的多份田野筆記濃縮成學術結構分明的長篇論文初稿。
範例 03 · 軟體研發工程師

架構決策紀錄 (ADR) 與 API 規格書自動產出

工具: gdocs_draft, gdrive_share

痛點情境：在 IDE 本地完成新版認證模組的重構後，需要寫一份架構設計文件給其他前後端成員審閱。

> 「根據我們剛才重構的 JWT 與 Refresh Token 認證邏輯，在 Google Docs 上建立一份『ADR-012: OAuth2與雙Token認證架構決策書』，詳細列出背景、考量方案比較、架構循序圖說明、API 端點清單與安全防護措施，完成後將文件設定為公司群組可註解（Commenter）並提供連結。」
預期效益：工程師無需離開 AI 開發環境即可完成團隊技術文檔的起草與權限指派。
範例 04 · 產品經理 (PM)

競品調研資料萃取與 PRD 產品需求規格書撰寫

工具: gdrive_search, gdocs_draft

痛點情境：收集了 3 份競品分析 PDF，需要提煉關鍵差異並撰寫下一季度「智慧搜尋功能」的 PRD。

> 「搜尋我 Google Drive 裡檔名包含『競品分析』的所有文件，比對各家在搜尋過濾機制上的優劣勢，在『產品規格』資料夾開一份『PRD: 2026 Q1 全域智慧搜尋需求規格書』，包含用戶故事（User Story）、功能範圍、驗收條件（AC）與資料欄位定義。」
預期效益：快速從大量分析資料中提取精華，產生標準化、工程師看得懂的 PRD。
範例 05 · 專案管理 / 行政秘書

會議錄音逐字稿濃縮、決議清單與行動事項 (Action Items)

工具: gdrive_download, gdocs_draft, gdrive_share

痛點情境：開完 1 小時跨部門產銷協調會，上傳了長達萬字的逐字稿文字檔，需盡快寄發正式會議紀錄。

> 「讀取我剛上傳到 Drive 根目錄的『20261123_跨部門會議逐字稿.txt』，過濾閒聊贅字，提煉出三大核心討論議題、五項關鍵決議，以及帶有指派人（Owner）與完成期限（Deadline）的行動清單，產出一份正式的 Google Docs 會議紀錄，並設定為任何人持連結可檢視。」
預期效益：會議結束 3 分鐘內產出條理清晰的行動事項表，大幅提高跨部門執行力。
範例 06 · 行銷與內容創作者

品牌風格長篇文章起草與多平台社群文案矩陣

工具: gdrive_search, gdocs_draft

痛點情境：需要依據公司 Drive 中的品牌語調指引（Tone of Voice），為新功能撰寫 2,000 字官方部落格文章與社群貼文。

> 「搜尋我雲端硬碟中的『品牌風格指南.pdf』，以專業且親切的筆觸，在 Google Docs 開一份名為『AI開發新時代_官方專案發布稿』。文章需包含吸睛引言、三大亮點深度介紹、實測數據圖表位置提示，並在文章文末追加適用於 Facebook、LinkedIn、X (Twitter) 的不同長度推廣文案。」
預期效益：一篇核心文章自動延伸為社群傳播矩陣，品牌調性統一不走味。
範例 07 · 法務與合約審查

多份採購合約跨版本條款交叉比對與合規風險報告

工具: gdrive_download, gdocs_draft

痛點情境：合作夥伴寄來了修改後的合約 PDF，需與 Drive 中既有的標準合約範本對照，抓出不利條款。

> 「下載並比對我 Drive 裡的『標準供應商協議_v2.pdf』與『廠商回簽修改版_2026.pdf』，特別聚焦在智慧財產權歸屬、保密條款與違約賠償上限。在 Google Docs 起草一份『合約審查風險備忘錄』，以表格標出修訂前後差異、潛在法律風險與建議修改條文。」
預期效益：大幅減少律師與法務人員人工比對逐行條文的心力，敏銳抓出陷阱條款。
範例 08 · 跨團隊主管 / 部門主管

季度 OKR / KPI 部門彙報彙整與管理層執行摘要

工具: gdrive_search, gdocs_draft

痛點情境：季末需要將工程組、設計組、運營組分別提交的進度報告匯總成一份給 CEO 審查的總結。

> 「搜尋我雲端硬碟『2026_Q3部門彙報』資料夾下的所有 Google 文件，提取各組別的目標達成率（OKR）、關鍵亮點里程碑與當前阻礙（Blockers）。為我起草一份『Q3 跨部門營運總結報告』Google Docs，首頁放高階主管摘要（Executive Summary），次頁放各組數據比較表。」
預期效益：自動穿透多個分散資料夾，將繁雜的組別進度濃縮成具備決策價值的高階報告。
範例 09 · 技術客服主管 / 維運負責人

熱門客戶工單分析與客服知識庫 (KB) 標準 SOP 文件產出

工具: gdrive_download, gdocs_draft

痛點情境：客服常被重複問題轟炸，需要將累積的常見故障排除紀錄整理成標準知識庫。

> 「讀取 Drive 中這份『2026年10月份客戶諮詢統計.csv』，統計出現頻率最高的 5 大問題類型（如忘記密碼、發票載具綁定失敗、退款處理等），為客服團隊在 Google Docs 撰寫一份『客戶服務常見問題應對 SOP 手冊』，附上標準排解步驟與回覆話術模板。」
預期效益：將零散的客訴日誌迅速轉化為團隊共用的制度化知識資產，縮短新人培訓期。
範例 10 · 學生 / 考生

歷屆考古題檢索、錯題概念辨析與複習衝刺筆記本

工具: gdrive_search, gdocs_draft

痛點情境：在 Drive 收集了近 5 年的期末或國考考古題 PDF，需要針對常錯觀念做系統性統整。

> 「搜尋我 Drive 裡『歷屆試題』目錄下的所有 PDF，找出所有跟『光合作用與呼吸作用比較』相關的題目與解析，幫我建立一份『考前衝刺錯題與核心觀念筆記』Google Docs。請用對照表呈現兩者在場所、原料、產物與能量轉換的差異，並附帶 3 題經典易錯題防呆解析。」
預期效益：AI 成為專屬家教，自動將死板考古題轉化為觀念清晰的個人化精華考前寶典。

5. 如何在 Antigravity 中啟用與授權？

Google 官方套件使用標準 OAuth 2.0 協議，資料傳輸安全無虞：

步驟 1：安裝套件

在左側邊欄「Skills & Customizations」搜尋 Google Docs 或 Google Drive，或對 AI 說「我想安裝 Google Docs」點擊卡片一鍵安裝。

步驟 2：登入授權

首次呼叫時，系統會彈出 Google 官方授權視窗，選取您要關聯的 Google 帳號（個人 Gmail 或 Google Workspace 學校/公司帳號）。

步驟 3：開始協同作業

授權完成後 Token 自動儲存於本機安全金鑰庫，隨時可在對話框用自然語言指示 AI 讀檔、查資料與寫文章！

6. 常見問題與安全性 (FAQ)

Q1：AI 能讀取我 Google Drive 裡的所有隱私檔案嗎？安全嗎？

只有在您發出明確提示詞（如「讀取某某檔案」或「搜尋特定資料夾」）時，擴充套件才會按需存取該指定檔案。所有連線皆走 Google 官方加密 API，不會擅自後台爬取或將未經許可的檔案外洩。

Q2：AI 建立的 Google Docs 檔案會存放在哪裡？

預設會儲存在您 Google 雲端硬碟的「根目錄（我的雲端硬碟）」。若您在對話中特別指名「存放在『教學備課』資料夾」，AI 就會自動先尋找該資料夾的 ID，並將文件直接歸檔至該目錄中。

Q3：它可以和 Google Sheets 或 Google Slides 一起連動嗎？

可以！這正是 Google 家族的強項。例如您可以指示 AI「先讀取 Google Drive 裡的試算表（Sheets）做統計分析，再把總結分析報告寫成一份 Google Docs，最後轉成簡報投影片」。
