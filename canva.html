Canva AI 視覺設計與行銷自動化

透過自然語言指揮全球領先的視覺設計平台 Canva。無需手動一張張點擊複製，Antigravity 能從試算表批次套印 100 份宣傳海報、自動將單一視覺重適配至 IG/TikTok/YouTube 6 大社群尺寸、利用 AI 去背並分離圖層，甚至自動讀取協同評論並精準修改設計！

1. 功能概述與生態架構

傳統視覺設計面臨「改字改圖繁瑣」、「全平台尺寸需手動調整」、「品牌配色常脫靶」等痛點。Antigravity 的 Canva 擴充套件由三大支柱組成，讓行銷企劃、產品設計師與開發工程師都能釋放視覺產能：

原生 Canva MCP 伺服器

提供超過 35 個底層 API 工具，涵蓋設計建立、元素精確修改、非同步去背、圖層分離、範本檢索與雲端資料夾管理。

7 大工作流 Skills

將複雜的多步驟設計操作封裝成高級智慧技能，如批次套印 (bulk-create)、社群尺寸轉換 (resize-for-social-media) 與品牌核查。

Canva CLI (canva api)

專為工程師與 CI/CD 管線打造的命令列工具，支援本機素材上傳、自動批次匯出高解析 PNG/PDF 並整合進自動發布流水線。

2. 這個功能能做什麼？

表格資料批次大量生成 (Bulk Create)

上傳或貼上 CSV/JSON 表格（如商品清單、活動嘉賓名單、學員證書），AI 自動比對品牌範本的標籤欄位（`{{name}}`、`{{price}}`、`{{photo}}`），一次自動產生數十到數百份客製化設計。

全通路社群媒體尺寸自適應 (Smart Resize)

只需一張主視覺，自動衍生出 Instagram 正方形貼文 (1:1)、限時動態 / Reels (9:16)、YouTube 封面縮圖 (16:9)、Facebook 橫幅與 LinkedIn 尺寸，並智能保持安全區域 (Safe Area) 不裁切主體。

AI 智慧去背與多圖層分離 (Layer Separation)

一鍵調用 Canva 雲端影像引擎，將靜態圖片的前景主體（人物、商品、吉祥物）乾淨去背，或將單一平面點陣圖切分分解為多層可獨立編輯位移的圖層。

品牌規範自動核查 (Brand Checker)

自動將設計與企業 Brand Kit（品牌色票、標準字型、Logo 邊界）進行逐頁比對，標註非標準色碼、字型違規或標誌變形，確保所有宣傳物 100% 符合品牌規範。

3. 7 大專屬工作流技能 (Canva Skills)

Antigravity 已內建 7 個高度優化的 Canva 專屬技能，能根據使用者的自然語言意圖自動觸發：

canva-bulk-create
表格資料批量套印

輸入 CSV/Excel 資料與品牌範本 ID，自動一對一填入文字與替換資產，產出整組設計。

canva-resize-for-social-media
社群全通路尺寸重構

查詢標準頻道格式表，自動生成 TikTok, IG, FB, X, YouTube 適用規格之副本並返回連結。

canva-brand-check
品牌手冊規範檢核

唯讀比對 Brand Kit 與頁面元素，輸出 On brand / Off brand / 待確認之審查報告。

canva-design-feedback
專業視覺評鑑與診斷

客觀分析視覺層次 (Hierarchy)、版面留白、易讀性 (Contrast) 與排版結構並給予具體建議。

canva-edit-design
精準編輯與版面修改

安全交易機制：替換字樣、修改字級色彩、調整元素座標尺寸、增刪或替換圖片。

canva-implement-feedback
審閱評論一鍵實裝

自動遍歷設計上的批註與評論線程 (Comments)，將具體修改意見自動套用回畫布。

canva-cli
命令列與自動化整合

在終端機中以 `canva api` 執行資產同步、匯出 PDF/PNG、非同步工作進度輪詢與腳本整合。

範例 01 社群行銷經理：一鍵將主視覺重適配至 6 大社群平台尺寸並檢視安全區

情境描述： 設計師完成了一款 1200x630 的官網活動橫幅，需在 10 分鐘內產出 IG 正方形貼文、IG 限時動態、YouTube 縮圖、TikTok 影片封面等全部規格。 

請調用 `canva-resize-for-social-media` 技能，處理我當前的活動主視覺：
1. 目標設計 URL / ID：`https://www.canva.com/design/DAG.../view`。
2. 請根據標準社群規格表，為我批次建立以下平台的自適應版本副本：
   - Instagram Post (1080 x 1080 px, 1:1)
   - Instagram Story / Reels (1080 x 1920 px, 9:16)
   - YouTube Thumbnail (1280 x 720 px, 16:9)
   - Facebook Cover (820 x 312 px)
   - LinkedIn Sponsored Content (1200 x 627 px)
3. 嚴格遵守「安全邊界 (Safe Area)」原則：在 9:16 的直式限動中，請提醒標題文字避開頂部 250px 帳號列與底部 350px 留言按鈕區。
4. 完成後列出這 5 個新設計的編輯連結 (Edit URLs) 與預覽縮圖。
預期執行成果：

AI 自動呼叫 resize-design 建立 5 個獨立規格專案，並列出包含 Safe Area 避讓說明的專屬編輯連結。

範例 02 電商營運企劃：透過 CSV 表格批次套印 50 款特惠商品促銷海報

情境描述： 雙 11 大促即將到來，需根據商品管理試算表自動將 50 款特價商品的品名、原價、大促折扣價與商品去背圖套印至官方促銷範本中。 

請使用 `canva-bulk-create` 技能為我執行批次海報生成作業：
1. 品牌範本搜尋：請檢索我 Canva 團隊中的「2026 雙十一主打促銷海報」Brand Template。
2. 檢查範本結構：讀取該範本的欄位 Schema（確認包含 `product_name`、`original_price`、`sale_price`、`hero_image`）。
3. 資料來源：讀取我本機資料夾中的檔案 `data/campaign/double11_products.csv`。
4. 欄位自動對齊：
   - CSV `商品名稱` -> `product_name`
   - CSV `原價` -> `original_price`
   - CSV `特價` -> `sale_price`
   - CSV `圖片素材ID` -> `hero_image`
5. 執行生成：請一次產生 50 份專屬商品海報，命名為「雙十一特惠_[商品名稱]」，並將成果儲存至 Canva 資料夾「2026大促促銷物料」中。
預期執行成果：

AI 自動解析 CSV 與範本資料集，透過 autofill-design 批次產出 50 份海報並分類歸檔至指定資料夾。

範例 03 品牌總監：品牌手冊自動稽核 (Brand Check)，抓出脫靶色票與違規字型

情境描述： 外部行銷代操團隊提交了下季度社群懶人包，需審查其是否嚴格遵守公司 Brand Kit 的標準色碼與專屬字型。 

請啟用 `canva-brand-check` 技能，對外部繳交的簡報設計進行嚴格品牌合規稽核：
1. 目標設計 ID：`DAFx8...`。
2. 品牌工具包：比對我團隊中的「Enterprise Core Brand Kit 2026」。
3. 執行檢驗維度：
   - 【色彩色碼】逐頁比對背景、標題文字、圖標色彩是否落在品牌 5 色盤中。若發現非規範色碼（如 `#FF3B30`），請標記該頁碼並推薦最相近的品牌標準色（如 `#E11D48`）。

預期執行成果：

AI 透過唯讀交易檢索色彩與字體屬性，精準列出第 3 頁色碼違規與第 5 頁字型不符之具體修正建議報告。

6. 視覺設計與防呆四大守則

守則一：社群縮放務必保留安全邊界 (Safe Area)

在 9:16（IG Reels, TikTok, YouTube Shorts）直式內容中，頂部 250px 通常會被平台頂部狀態欄遮擋，底部 350px 則會被作者頭像、文案與互動按鈕覆蓋。關鍵標題與核心主體必須保持在垂直居中的 1080x1320px 安全區域內。

守則二：唯讀交易機制 (Read-only Transaction)

在執行品牌規範檢查（Brand Check）時，Antigravity 嚴格採用「啟動交易 -> 檢驗元素 -> 取消交易 (Cancel Transaction)」的防禦流程，絕不意外觸發自動儲存或污染使用者的原始設計。

守則三：多語系文字長度預留防破版

英文字串翻譯為德語時通常字元增加 30%，翻譯為中文或日文時字元縮短但字高增加。批次套印或多語系替換時，應預先設定「等比縮小文字以符合文字框 (Shrink text on overflow)」。

守則四：非同步工作 (Async Job) 指數退避輪詢

去背、圖層分離與高解析 PDF 匯出均為伺服器端耗時任務，回傳狀態為 in_progress。自動化程式不得進行高頻無間隙輪詢，應遵循指數退避原則，避免觸發 API 頻率限制。

8. 常見問題與除錯指南 (FAQ)

Q1: 執行時出現「Missing scopes: [brandkit:read]」或權限不足錯誤？

這是因為 Canva 最近新增了進階範圍權限。請在 Antigravity 外掛管理員中，將 Canva 連線先「中斷連線 (Disconnect)」並「重新連線 (Reconnect)」，在彈出的權限勾選頁中確認勾選「存取品牌工具包 (Brand Kits)」與「設計讀寫」即可解決。

Q2: 批次大量套印 (Bulk Create) 時，如何處理圖片欄位？

Canva 的範本圖片欄位需要有效的 Canva 資產 ID（`asset_id`）。如果您的 CSV 中是本機檔案路徑或公開圖片 URL，Antigravity 會先透過 upload-asset-from-url 工具將圖片非同步上傳至 Canva 資產庫取得 ID，再自動填入範本對應位置。

Q3: 為什麼 Brand Check 有時無法直接讀取色碼 Hex 數值？

部分 Canva API 端點僅暴露縮圖與元件位置。此時技能會自動切換為「高精度視覺縮圖交叉比對 (Visual Thumbnail Check)」，並主動詢問使用者貼上品牌專屬色票 Hex，達到雙重驗證而不憑空瞎猜。

Q4: 匯出高解析度列印 PDF 時工作卡住或等太久？

頁數超過 50 頁或含有多張 4K 點陣圖的設計匯出可能需要 30-60 秒。Antigravity 內建工作 ID 追蹤，若未即時完成會返回 Job ID，您隨時可以要求「檢查剛剛的匯出進度」接續取得下載連結。
