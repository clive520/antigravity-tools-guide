Unity Editor 遊戲引擎與場景自動化編排指南

透過 Model Context Protocol (MCP) 與 Unity 編輯器原生 C# Bridge，打破代碼編輯器與遊戲引擎介面的藩籬。AI 代理能直接在 Hierarchy 中建立 GameObject、配置物理組件、觸發自動化測試，並讀取 Console 錯誤進行自愈！

2. 使用者基本條件與環境需求

1. 軟體環境條件
  • Unity 編輯器版本：Unity 2021 LTS、2022 LTS 或 Unity 6+（個人免費版即可）。
  • C# 橋接外掛：專案 Assets 內已導入 MCPBridge.cs。
2. 硬體規格建議
  • 記憶體 (RAM)：建議 16GB+ RAM（大型遊戲專案烘焙光照推薦 32GB）。
  • 顯示卡：獨立顯卡（GTX 1660 / RTX 3060 以上，或 Apple Silicon M 系列）。
3. AI 多模態模型
  • 搭配 Claude 3.5 Sonnet 或 Gemini 2.0，能自動閱讀 GameView 畫面與 Console 報錯進行代碼自我修復。
4. 安全與技能門檻
  • 本機沙盒通訊：WebSocket 僅監聽本機 127.0.0.1:8080。
  • 新手友善：初學者可用口述搭建場景 Prototype，老手可用於自動化管線。

3. 這個功能能做什麼？

Hierarchy 場景樹物件動態生成

一句話建立相機、光源、地板與帶碰撞體的立方體障礙物，並自動維持嚴謹的父子階層結構。

Inspector 組件掛載與參數微調

自動為物件掛載 Rigidbody（剛體）、BoxCollider、NavMeshAgent，並精準修改 Mass 與 Drag 物理數值。

Console 報錯捕捉與代碼自愈

讀取 Editor Console 紅字報錯堆疊，AI 自動分析 NullReferenceException 或編譯錯誤，修改代碼後觸發熱重載。

自動化單元測試與功能表命令

一鍵執行 Unity Test Runner 測試套件，或執行 AssetDatabase.Refresh 與專案建置 Build Pipeline。

4. 核心工具架構與 API

工具名稱 呼叫參數 功能說明
unity_create_gameobject name, primitive_type, position, rotation, parent 在當前場景中建立全新遊戲物件並設定世界座標。
unity_set_component_property target_object, component_name, property_values 為物件掛載組件並在 Inspector 中設定其屬性數值。
unity_get_scene_hierarchy root_name? 檢索場景中所有物件階層樹、Tag、Layer 與組件清單。
unity_run_tests_and_get_logs mode: "EditMode" | "PlayMode" 執行自動化測試並抓取 Console 最新報錯記錄。
unity_execute_menu_item menu_path: string 執行頂部功能表命令（如 "Assets/Refresh"、"File/Save"）。

5. 10 大跨角色實戰 Prompt

涵蓋獨立遊戲、關卡設計、音效程式、UI 架構、物理模擬與 Console 錯誤自愈多角實戰

10 個高階範例
角色 01 獨立遊戲開發者 · 3D 角色控制器 Prototype 一鍵搭建
unity_create_gameobject

場景情境：需要快速在空場景中搭建可移動的玩家角色控制器與地板。

請使用 Unity MCP 建立玩家角色 Prototype：
1. 建立一個 50x1x50 的平面 Floor（掛載 BoxCollider）。
2. 在座標 (0, 1.5, 0) 建立名為 `Player` 的膠囊體 (Capsule)。
3. 為 Player 物件掛載 Rigidbody（勾選 Freeze Rotation X 與 Z），並掛載 CharacterController 組件。
4. 在 Player 上方添加子攝影機 Main Camera（座標 0, 0.8, 0），並將 Directional Light 旋轉 45 度模擬陽光。
角色 02 關卡設計師 · 隨機生成 20 個障礙物並烘焙尋路網格
unity_create_gameobject 
請為當前地圖生成隨機迷宮障礙：
1. 在 40x40 區域內隨機分佈生成 20 個立方體障礙物（長寬 2x2，高度隨機 2~4m）。
2. 將所有障礙物設為 Static（Navigation Static 勾選）。
3. 執行選單命令觸發 Unity NavMesh 烘焙，並回傳烘焙成功狀態。
角色 03 遊戲音效程式員 · 批次掛載 3D 空間音效與衰減曲線
unity_set_component_property 
請掃描場景中所有 Tag 為 `Enemy` 的物件：
1. 為每個敵人掛載 AudioSource 組件。
2. 將 Spatial Blend 屬性調整為 1.0 (完全 3D 空間音效)。
3. 設定 3D 音效衰減模式為 Logarithmic Rolloff（Min Distance: 2m, Max Distance: 25m）。
角色 04 遊戲 UI/UX 架構師 · 自動建立 Canvas 血條與 HUD 介面
unity_create_gameobject 
請建立遊戲 HUD 介面樹：
1. 建立 Canvas（Render Mode 設為 Screen Space - Overlay，UI Scale Mode 設為 Scale With Screen Size）。
2. 在左上角建立生命值 Slider（紅色填充條），附帶 TextMeshPro 生命數值。
3. 在右上角建立金幣收集圖標與動態計數文字。
角色 05 物理模擬工程師 · 骨牌連鎖碰撞連鎖反應
unity_set_component_property 
請建立多米諾骨牌實驗：
1. 沿曲線路徑均勻排布 30 片骨牌（寬 0.2m、高 1.0m、厚 0.1m，間距 0.5m）。
2. 每片骨牌掛載 Rigidbody（Mass 0.2kg）與 BoxCollider。
3. 在第一片骨牌後方施加初始推力 (AddForce)。
角色 06 遊戲 QA 自動化測試員 · 執行單元測試並捕捉 Console 報錯
unity_run_tests_and_get_logs 
請呼叫 unity_run_tests_and_get_logs 執行 EditMode 測試：
1. 抓取 Console 報錯堆疊。
2. 若有 NullReferenceException 或編譯警告，指出出錯的腳本與代碼行數。
角色 07 特效美術師 · 爆炸火球粒子系統 (Particle System)
unity_set_component_property 
請建立爆炸粒子特效 GameObject：
1. 掛載 Particle System 組件，發射形狀設為 Sphere（半徑 0.5m）。
2. 粒子生命週期 1.2 秒，起始顏色漸變（亮黃 ➔ 熾紅 ➔ 灰黑煙霧）。
3. 疊加一個瞬間爆炸的 Point Light（強度 8.0，半徑 12m）。
角色 08 多語在地化專員 · 批次替換 TextMeshPro 文本鍵值
unity_get_scene_hierarchy 
請檢索所有 UI 元件：
1. 找出所有硬編碼中文的 TextMeshPro 元件。
2. 匯出其路徑與文本內容為 JSON 鍵值對，以便進行多語 Localization 替換。
角色 09 VR/AR 互動工程師 · 配置 XR Origin 與雙手射線交互
unity_create_gameobject 
請建立 XR VR 場景基礎設施：
1. 建立 XR Origin（追蹤空間設為 Floor）。
2. 在 Left/Right Controller 掛載 XR Ray Interactor 與直線光束渲染 (LineRenderer)。
角色 10 AI 架構總監 · 場景清理與孤兒節點自動修復（場景自檢）
unity_get_scene_hierarchy 
請擔任 Unity 專案架構師，執行場景全檢與自愈閉環：
1. 檢索當前場景所有 GameObject，標記所有包含 `Missing (Mono Behaviour)` 的損壞元件。
2. 找出未掛載任何組件且沒有子物件的孤兒空物件，主動移除。
3. 檢查所有 Camera 與 AudioListener，確保場景中僅有一個激活的 AudioListener 避免警告。
4. 整理完畢後自動執行保存場景命令 (Save Scene)。

6. 安裝與設定教學

1 導入 Unity MCPBridge.cs 外掛

將 MCPBridge.cs 複製進 Unity 專案的 Assets/Editor/ 資料夾內。編譯後上方工具列將出現「MCP ➔ Start Server」選單。

2 配置 Antigravity / Claude 設定檔 
{
  "mcpServers": {
    "unity": {
      "command": "npx",
      "args": ["-y", "unity-mcp"],
      "env": {
        "UNITY_PORT": "8080"
      }
    }
  }
}

7. 常見問題 (FAQ)

在 PlayMode 運行時 AI 所做的修改會保留嗎？

Unity 預設在 PlayMode 運行時的修改會在退出遊戲時重置。AI 會在非運行狀態 (EditMode) 進行場景搭建與 Prefab 保存，確保所有幾何與組件變更永久持久化。
