2. 使用者基本條件與環境需求

1. 軟體環境條件
  • Inkscape 主程式：需安裝 Inkscape 1.2 或 1.3+（官方免費開源）。
  • 命令列支援：確認系統 PATH 包含 inkscape 命令。
2. 硬體規格建議
  • 記憶體 (RAM)：最低 4GB（複雜向量節點超過數萬點時推薦 8GB+）。
  • 一般辦公電腦即可順暢執行，無特殊獨立顯卡要求。
3. AI 多模態模型
  • 搭配 Claude 3.5 Sonnet 或 Gemini 2.0，能檢視向量渲染圖並微調錨點曲率。
4. 安全與技能門檻
  • 零向量手繪門檻：口述幾何意圖即可生成精準閉合路徑。
  • 本機封閉離線運行：保障企業商標與商業設計圖產權安全。

3. 這個功能能做什麼？

向量幾何路徑與貝茲曲線生成

以數學坐標直接構建黃金比例圓弧、封閉多邊形與三次貝茲曲線，徹底告別手工鋼筆節點歪斜。

路徑布林運算與鏤空差集

自動將文字與幾何圖形進行相加 (Union)、相減 (Difference) 與分割 (Division)，輕鬆做出鏤空 LOGO。

雷射切割刀模與包裝展開圖

精準標註 0.01mm 紅色切割線與藍色雕刻線，自動生成紙盒刀模展開圖與卡榫接縫間隙。

標準無損向量 PDF 與 SVG 輸出

輸出極度精簡的乾淨 SVG 代碼（適合 Web 前端）或印刷級向量 PDF，保證無限放大永無鋸齒邊緣。

4. 核心工具架構與 API

工具名稱 呼叫參數 功能說明
inkscape_create_path path_data, fill_color, stroke_color, stroke_width 依據 SVG 語法在畫布建立多邊形、圓弧或貝茲曲線路徑。
inkscape_boolean_operation op: "union" | "diff" | "intersection", id1, id2 為兩個或多個向量物件執行聯集相加、相減差集或交集。
inkscape_transform_node node_id, transform_type, values 縮放、旋轉、平移或平滑節點錨點曲率。
inkscape_query_svg_dom selector: string 檢索 SVG 內部節點結構、圖層分組與樣式屬性。
inkscape_export_format output_file, format: "svg" | "pdf" | "png" | "dxf" 一鍵匯出為乾淨 SVG、向量 PDF 或雷射切割 DXF。

5. 10 大跨角色實戰 Prompt

涵蓋企業 LOGO、向量圖示、雷切創客、包裝刀模與學術圖表多角實戰

10 個高階範例
角色 01 企業識別 (CIS) 設計師 · 黃金比例極簡科技商標 LOGO
inkscape_boolean_operation 
請使用 Inkscape 幾何運算建構極簡科技商標：
1. 繪製半徑 100px 的外圓 A，與半徑 60px 的同心內圓 B。
2. 執行差集 (Difference) 得到寬度 40px 的圓環。
3. 在右上方以 45 度角切出一道寬度 20px 的開口。
4. 填入漸層色（深藍 #0f172a ➔ 琥珀金 #f59e0b），並匯出為乾淨 SVG 代碼。
角色 02 向量圖示 (Icon) 繪師 · 24x24 網格線性導航圖標組
inkscape_create_path 
請繪製符合 Feather / Lucide 風格的 Home 主頁圖標：
1. 畫布設為 24x24 像素，viewBox="0 0 24 24"。
2. 繪製房屋輪廓路徑：屋頂尖角 (12, 3)，屋簷 (2, 12)，底座 (20, 21)，門洞 (9, 21) 至 (15, 15)。
3. 設定線條寬度 2px，線端 round (圓頭)，拐角 round (圓角)。
角色 03 雷射切割創客 · 壓克力收納盒卡榫展開刀模圖
inkscape_export_format 
請建立 3mm 壓克力互鎖收納盒刀模展開圖：
1. 建立 100x100x60mm 盒子之底板與四面側板。
2. 邊緣生成 10mm 寬之公母齒接卡榫（考慮 0.1mm 激光切割燒蝕補償 Kerf）。
3. 切割線設為純紅色 (#ff0000, 0.01mm 髮絲線)，匯出為 DXF 與向量 PDF。
角色 04 包裝工程師 · 標準折疊紙盒刀模線與壓痕虛線
inkscape_create_path 
請繪製標準化化妝品外包裝紙盒刀模：
1. 實線 (Solid Red #ff0000)：外部裁切刀線與插舌鎖扣。
2. 虛線 (Dashed Green #00aa00)：內部折疊壓痕線 (Crease Line)。
3. 外圍擴展 3mm 印刷出血安全線 (Bleed Line)。
角色 05 學術圖表繪製員 · 期刊級出版向量折線與柱狀統計圖
inkscape_export_format 
請將實驗數據陣列繪製為高精度出版圖表：
1. 繪製 X/Y 直角座標軸與刻度線，標籤字型指定為 Arial 10pt。
2. 繪製三組實驗對照組柱狀圖，填入高對比色無障礙色票。
3. 匯出為符合 Nature 投稿標準之向量 PDF。
角色 06 字型設計師 · 幾何粗體展示字體輪廓建構
inkscape_transform_node 
請在 1000x1000 EM 空間設計幾何大寫字母「A」：
1. 主幹筆畫寬度均勻鎖定為 120px，外角施加 20px 圓角。
2. 中央橫桿高度置於字高 40% 處。
3. 將路徑轉為封閉複合輪廓 (Combined Path)，節點數精簡至最低。
角色 07 空間導向設計師 · 建築消防逃生動線向量標註
inkscape_create_path 
請在平面圖頂層繪製逃生動線：
1. 繪製綠色半透明發光箭頭線條 (#10b981, 寬度 6px)。
2. 在逃生出口處放置符合 ISO 7010 標準之綠色安全門圖標向量符號。
角色 08 文創印務專員 · 異形貼紙平滑外擴白墨保護層
inkscape_boolean_operation 
請為插畫物件生成貼紙白墨底版：
1. 選取插畫主體所有可見外輪廓路徑執行聯集 (Union)。
2. 執行外擴動態偏移 (Outset Offset) 2.5mm，並平滑尖銳死角。
3. 圖層命名為 `White_Ink_Underlay`，專用 Spot 色標註。
角色 09 資訊圖表 (Infographic) 視覺師 · 商業飛輪循環流程圖
inkscape_create_path 
請建立三段式環形飛輪圖表：
1. 繪製由 3 條弧形箭頭相互追逐形成的封閉循環環（半徑 180px）。
2. 三段分別填入三原色漸層，每個環段節點附加圓形文字框。
角色 10 AI 拓撲審核工程師 · SVG 重疊節點清除與封閉焊接（自檢閉環）
inkscape_query_svg_dom 
請擔任我的向量品質審查員：
1. 遍歷 SVG 文件內部所有 `` 標籤。
2. 檢查是否有重疊距離小於 0.05px 的多餘垃圾錨點並自動融合。
3. 檢查是否有未閉合但有填色的破損路徑，自動補完封閉「Z」指令。
4. 移除所有空的 `` 群組標籤，回傳瘦身前後的檔案大小比較。

7. 常見問題 (FAQ)

為什麼產出的 SVG 檔案可以直接貼到 HTML 中使用？

Inkscape MCP 預設採用「純粹 SVG (Plain SVG)」匯出模式，剝離了 Inkscape 私有的編輯器元數據，生成的代碼 100% 符合 W3C 規範，可直接內嵌於 React/Vue 元件或 Web 頁面中。
