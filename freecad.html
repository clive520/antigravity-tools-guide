透過 Model Context Protocol (MCP) 橋接開源世界最強大的參數化實體 CAD 系統。使用自然語言精確描述長寬高、工程約束、特徵挖孔與拔模倒角，AI 自動生成 PartDesign 特徵樹並一鍵匯出製造級 STEP 與 3D 列印 STL 檔案！

💡 為什麼工程製造必須用 FreeCAD 而非網格軟體？ 網格模型（如 OBJ/FBX）是由數以萬計的微小三角形平面拼湊而成，缺乏真實圓弧半徑與實體公差；而 FreeCAD 是 BREP（邊界表示法）實體幾何，圓形就是真正的數學圓，CNC 銑刀與 3D 切片軟體能精確解析加工路徑！

2. 使用者基本條件與環境需求

開始使用 FreeCAD MCP 前，請確認您的電腦設備與工作環境已滿足以下 5 大基礎條件：

1. 軟體環境條件（100% 免費開源）
  • FreeCAD 主程式：需已安裝 FreeCAD 0.20、0.21 或 1.0+（官方完全免費開源，無任何商業訂閱）。
  • Python 與套件工具：本機具備 Python 3.10+，推薦安裝 uv 以便執行 uvx freecad-mcp。
  • OpenCASCADE 核心支援：FreeCAD 官方安裝包已完整封裝幾何核心，無需額外編譯。
2. 硬體規格建議
  • 記憶體 (RAM)：最低 8GB（複雜零件布林裁切推薦 16GB 以上）。
  • 顯示卡：支援 OpenGL 3.0+ 即可流暢旋轉 3D 幾何實體。
  • 儲存空間：保留 2GB 空間存放 FreeCAD 本體與匯出之 STEP/STL 模型檔。
3. AI 客戶端與 Vision 多模態支援
  • 相容 MCP 之客戶端：Antigravity 2.0、Claude Desktop、Cursor 等。
  • Vision 視覺模型推薦：搭配具備多模態視覺辨識之 LLM（Claude 3.5 Sonnet / Gemini 2.0），能自動讀取等角軸測圖快照，檢驗螺絲孔位與壁厚。
4. 零程式門檻與本機安全防護
  • 零 CAD 程式基礎：只需以日常中文說明「長 100mm 寬 50mm 厚 10mm，兩端開 M5 貫通螺孔」，AI 自行轉譯。
  • 封閉沙盒執行：RPC 通訊僅限本機環回位址 127.0.0.1:9000，保障機構專利安全。

3. 這個功能能做什麼？

FreeCAD MCP 將傳統需要滑鼠拉扯約束的繁瑣 CAD 作業，轉變為工程意圖直達的代碼化生產力：

參數化 CSG 實體幾何建構

自然語言生成立方體、圓柱、球體，並自動執行布林聯集 (Fuse)、切除 (Cut) 與交集 (Common)，精準搭建多孔法蘭盤與機械外殼。

製造級 STEP 與 3D 列印 STL 匯出

完成幾何特徵後，一句話自動匯出乾淨水密（Watertight）的 .stl 供切片軟體列印，或輸出 .step 供 CNC 車銑複合加工。

特徵樹階層化管理與倒角

自動為實體邊緣施加 2mm 倒圓角 (Fillet) 或 45 度倒斜角 (Chamfer)，建立拔模斜度與加強肋骨，特徵歷史完整保留可隨時回溯。

等角軸測圖快照視覺自檢

調用 freecad_get_view_screenshot 擷取 3D 視角截圖，AI 自主檢查孔位是否打偏、外壁是否過薄，達成幾何自檢閉環。

4. 核心工具架構與 API

FreeCAD MCP 伺服器提供 5 大核心工具，全方位覆蓋 CAD 建模、特徵調整與工程匯出：

工具名稱 呼叫參數 (Arguments) 功能說明
freecad_create_primitive type, length, width, height, radius 在當前文件中建立標準幾何圖元（Box 立方體、Cylinder 圓柱體、Sphere 球體）。
freecad_run_code code: string 執行 FreeCAD Python 腳本，呼叫 Part 或 PartDesign 模組執行布林切除與倒角。
freecad_export_file object_name, file_path, format 將指定物件或整體裝配匯出為 .stl（3D 列印）、.step（工程製造）或 .dxf。
freecad_get_document_info 無參數 查詢當前文件物件清單、特徵樹依賴關係、體積 (Volume) 與表面積幾何屬性。
freecad_get_view_screenshot view_type?: "Isometric" | "Top" | "Front" 擷取指定視角之高解析 3D CAD 等角軸測或正交三視圖快照，供視覺 AI 自我審核。

6. 安裝與設定教學

只需 3 步驟即可完成本機 FreeCAD 與 AI 代理之 MCP 通訊對接：

1 安裝 FreeCAD 官方主程式與 Python 環境

自 freecad.org 下載安裝 FreeCAD 0.21 或 1.0 版本。安裝完成後請確保本機命令列具備 Python 3.10+。

在 antigravity.json 或 claude_desktop_config.json 設定檔中加入： 

{
  "mcpServers": {
    "freecad": {
      "command": "uvx",

      "env": {
        "FREECAD_RPC_PORT": "9000"
      }
    }
  }
}
3 重啟客戶端並測試第一條幾何命令

發送測試提示詞：
「請在 FreeCAD 中建立一個 50x50x50mm 立方體，並在正中央貫穿一個直徑 20mm 的圓孔。」

7. 常見問題 (FAQ)

什麼是拓撲命名問題 (Topological Naming Problem)？AI 如何避開？

在舊版 CAD 中，當上游特徵修改後，下游面（Face1, Face2）的編號可能會亂跳導致破面。FreeCAD 1.0+ 已原生整合 LinkStage3 拓撲命名解決方案；此外，AI 透過基準面 (Datum Plane) 錨定特徵，從根源避免依賴易跳號的邊界索引。

沒有圖形介面（Headless 無頭模式）也能讓 AI 產出 3D 模型嗎？

可以！FreeCAD 本體完全支援以純命令列無頭模式 (`FreeCADCmd`) 運行。AI 可以在雲端伺服器或本機背景執行 Python 幾何建構腳本，並直接產出 STL 或 STEP 檔案，不一定非要開啟視窗。

匯出的 STEP 檔案可以用在 SolidWorks 或 Fusion 360 嗎？

完全可以！STEP (ISO 10303) 是全球機械與工業製造領域的絕對通用標準交換格式。不論是 SolidWorks、Autodesk Inventor、Fusion 360 還是 Siemens NX，均能 100% 原始解析模型實體幾何。
