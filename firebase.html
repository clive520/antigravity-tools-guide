2. 這個功能能做什麼？（全端無伺服器架構）

Firestore 即時 NoSQL 資料庫

自動建立集合（Collections）與文件（Documents），支援即時數據同步（Real-time listeners）與離線本地快取。

Firebase Authentication 身分驗證

幾行代碼快速搞定 Google 一鍵登入、Email 密碼認證、手機簡訊 OTP 與匿名登入，省去自建 JWT 認證的資安風險。

Firebase Hosting 全球 CDN 部署

一鍵將 Vite、Next.js、React、Vue 靜態與 SSR 應用發布至 Google 全球邊緣伺服器，自動配發免費 SSL 證書與自訂網域。

Cloud Functions 伺服器雲端函式

編寫事件驅動微服務：資料庫寫入時觸發發信、用戶註冊時建立初始檔案、定時 Cron 排程執行資料備份與清理。

Security Rules 安全規則智慧審查

自動檢核 Firestore 與 Storage 安全規則，杜絕「開放任何人讀寫（read/write: if true）」的嚴重資料洩漏漏洞。

Remote Config 遠端動態開關

無需重新打包發布 App 或網頁，在雲端動態調整營銷活動開關、版本升級提醒與進行 A/B 測試。

3. 核心工具架構與 CLI 整合

Firebase 擴充套件原生結合 Firebase Admin SDK、Firebase CLI (`firebase-tools`) 與 Google Cloud 權限架構，讓 AI 能從環境初始化、架構代碼生成到終端部署全程自動化。

5. Firebase 安全規則 (Security Rules) 黃金範本

// 杜絕漏洞的標準身分隔離規則範例
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 嚴格限制：使用者只能讀寫屬於自己的資料文件
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    // 公開文章：所有人可讀，但僅有登入者可發表
    match /posts/{postId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null && resource.data.authorId == request.auth.uid;
    }
  }
}

6. 常見問題與除錯 (FAQ)

Q1：Firebase 的免費額度（Spark Plan）夠個人或中小型專案使用嗎？

非常充裕！Firestore 提供每天 50,000 次讀取與 20,000 次寫入、Authentication 支援每月高達 50,000 位活躍用戶，Hosting 提供 10GB 儲存與每月 360MB/天流量。對個人或中小型 MVP 產品而言幾乎完全免費。

Q2：它和傳統關聯式資料庫（如 MySQL / PostgreSQL）有何不同？

Firestore 是靈活的 NoSQL 文件型資料庫（Document Database），不需要預先定義 Schema 或繁瑣的 Migration，直接存取 JSON 物件，特別適合敏捷開發與移動端即時同步。

Q3：如何在 Antigravity 中登入綁定我的 Firebase 專案？

只要在專案根目錄執行 firebase login 完成 Google 帳號授權，AI 就能在對話中直接透過 CLI 指令幫您讀取專案列表並執行部署。
