Cloudflare 擴充功能實戰指南
邊緣無伺服器微服務、D1/R2 儲存與 WAF 防護

透過 Antigravity 的 Cloudflare 專屬生態外掛，AI Agent 能直接在終端管理全球 CDN 快取規則、調用 Workers 撰寫邊緣地理位置路由、維護分散式 D1 SQLite 資料庫、操作零出口傳輸費之 R2 儲存桶，並一鍵套用 WAF 安全防護規則。

1. 功能概述與生態定位

在現代雲端開發中，傳統中心化雲端伺服器（Centralized Cloud）常受限於跨國網路延遲（High Latency）與高昂的頻寬出站費用（Egress Fees）。Cloudflare 提供了覆蓋全球 330 多個城市的邊緣網路（Edge Network），使運算與儲存直接發生在終端使用者的毫秒級身旁。

極速邊緣冷啟動 (0ms)
基於 V8 Isolates 架構，Workers 幾乎沒有冷啟動延遲，可在全球邊緣節點瞬間執行程式。
零頻寬出站費 (Zero Egress)
R2 物件儲存打破傳統雲端廠商的頻寬出口稅壁壘，節省高達 80% 以上的檔案傳輸成本。
邊緣 AI 模型推論 (Workers AI)
在邊緣直接調用開源頂尖大模型（Llama 3、Mistral、Whisper），免去自行管理 GPU 叢集的痛苦。

2. 這個功能能做什麼？

Cloudflare 整合套件賦予 Antigravity 4 大邊緣基礎建設掌控力：

邊緣無伺服器微服務 (Workers)

利用 JavaScript/TypeScript 撰寫邊緣反向代理、AB 測試分流、API Gateway 請求過濾與身份認證驗證，幾毫秒內全球同步部署。

邊緣無伺服器儲存矩陣 (D1 / R2 / KV)

D1 提供分散式關聯 SQLite 資料庫；R2 提供無出口費的 S3 兼容物件儲存；KV 提供全球超低延遲鍵值快取。

企業級 WAF 與智慧防護

一鍵調用 WAF 安全規則阻止 SQL Injection 與 XSS 攻擊、設定頻率限制 (Rate Limiting) 與驗證碼阻斷惡意爬蟲機器人。

DNS 解析與 SSL/TLS 自動化

自動化管理網域 DNS 記錄（A/CNAME/TXT/MX）、配置自動憑證輪轉，並強制開啟 Full (Strict) 端到端加密防線。

4. 10 大跨角色實戰 Prompt

覆蓋全端架構、資安 SRE、邊緣資料庫與靜態託管等多元實戰情境

10 個高階範例
角色 01 全端架構師 · 邊緣地理反向代理
cloudflare_workers

場景情境：為跨國 SaaS 系統在 Cloudflare Workers 部署邊緣路由，依據訪客地理位置（`request.cf.country`）自動反向代理至最接近的後端節點（亞洲/歐洲/美洲）。 

請使用 cloudflare_workers 撰寫並部署一個邊緣反向代理腳本「geo-edge-router」：
1. 讀取連線請求的地理資訊 request.cf.country。
2. 若來自 TW、JP、KR、SG 等亞洲國家，反向代理至 https://asia-origin.myapi.com；若來自歐洲國家則代理至 https://eu-origin.myapi.com；其餘統一導向美洲主節點。
3. 同時在 Response Header 加入「X-Edge-Region: [區域]」以利客戶端排錯。
4. 請輸出完整 TypeScript 代碼與 wrangler.toml 綁定設定。
預期成果：AI 生成具備完整型別的 Cloudflare Worker 原始碼，精確處理 `fetch` 轉發與自定義標頭，並提供本機預覽與發布指令。
角色 02 資安維運 SRE · WAF 防火牆自定義規則
cloudflare_waf

場景情境：官網近日遭遇惡意爬蟲針對 `/api/v1/auth/login` 進行撞庫與爆破攻擊，需在 Cloudflare 邊緣建立 WAF 規則與自定義 Managed Challenge。 

請使用 cloudflare 相關工具為網域「example.com」建立精準安全防護規則：
1. 目標端點：http.request.uri.path eq "/api/v1/auth/login"
2. 觸發條件：若連線來自已知爬蟲機器人（cf.client.bot eq true）或 1 分鐘內同一 IP 請求數超過 20 次。
3. 動作處置：對一般高頻訪客觸發「Managed Challenge (驗證碼)」，對惡意機器人與黑名單 ASN 直接採取「Block (阻斷)」。
4. 輸出規則表達式 (Expression Rule) 與部署配置。
預期成果：AI 提供符合 Cloudflare Firewall Rules 語法的精準布林表達式，並說明如何於儀表板或 API 快速套用生效。
角色 03 資料工程師 · Cloudflare D1 邊緣資料庫遷移
cloudflare_d1

場景情境：為全球邊緣部落格系統設計 Cloudflare D1 結構，包含文章表、分類標籤表，並撰寫高效分頁與索引 SQL 腳本。 

請使用 cloudflare_d1 為資料庫「edge_blog_db」規劃並執行結構遷移：
1. 建立「posts」表：包含 id (UUID)、slug (唯一索引)、title、content、published_at、view_count。
2. 建立「tags」與關聯表「post_tags」。
3. 建立複合索引加速首頁最新文章分頁查詢 (published_at DESC)。
4. 寫入 3 筆擬真測試資料，並示範在 Cloudflare Worker 中透過 env.DB.prepare 執行參數化安全查詢。
預期成果：AI 生成合規 SQLite DDL 檔案，並給出 Worker 程式碼範例，包含預編譯防範 SQL Injection 的實作方式。
角色 04 雲端成本優化師 · S3 零退出費遷移至 R2
cloudflare_r2

場景情境：公司每月被 AWS S3 收取數千美元出站頻寬費，需撰寫自動化搬遷評估，並利用 Cloudflare R2 取代 S3 提供圖片與備份儲存。 

請使用 cloudflare_r2 工具協助規劃 S3 至 Cloudflare R2 的無縫搬遷方案：
1. 建立名為「company-public-assets」的 R2 儲存桶，並綁定自定義子網域 cdn.company.com。
2. 配置 S3-compatible API 連線憑證與跨來源資源共享 (CORS) 政策（僅允許公司網域讀取）。
3. 撰寫 Node.js 腳本使用 @aws-sdk/client-s3 串接 R2 執行流式上傳 (Streaming Upload)。
4. 計算每月 10TB 流量下，相比 AWS S3 可節省的頻寬與儲存費用對照表。
預期成果：AI 提供 R2 CORS JSON 設定、相容 S3 SDK 的客戶端初始化代碼，以及清晰的 FinOps 成本省損評估表格。
角色 05 跨國電商工程師 · Workers KV 全球即時匯率快取
cloudflare_kv

場景情境：跨境電商需要每小時從中央匯率服務拉取最新幣別對照，並將匯率快照快取至全球邊緣 KV，確保商品換算延遲小於 10ms。 

請使用 cloudflare_kv 工具為跨國電商建立全域貨幣匯率快取管線：
1. 在命名空間「CURRENCY_RATES」中配置排程更新邏輯（Cron Triggers 每 60 分鐘觸發一次）。
2. Worker 抓取最新匯率資料後，寫入 key「rates:latest」，設定 TTL 為 7200 秒（容錯防呆）。
3. 實作結帳端點 GET /api/convert?from=USD&to=TWD&amount=100，直接在邊緣從 KV 讀取並完成計算後回傳 JSON。
4. 輸出包含 Cron 觸發與 HTTP 處理的單一 Worker 程式碼。
預期成果：AI 生成具備 `scheduled()` 與 `fetch()` 雙重事件監聽的 Worker 腳本，實現零後端伺服器依賴的邊緣即時匯率換算。
角色 06 AI 應用工程師 · Workers AI 邊緣模型即時推論
cloudflare_ai

場景情境：打造端到端無伺服器語音逐字稿與摘要服務，利用 Workers AI 邊緣直接執行 Whisper 與 Llama 3 雙模型。 

請使用 cloudflare 相關外掛撰寫一個整合 Workers AI 的無伺服器音訊轉錄與摘要 Worker：
1. 接收前端上傳的音訊檔案（POST /api/transcribe）。
2. 調用 Workers AI 模型「@cf/openai/whisper」將語音轉為文字。
3. 緊接著將轉錄文字送入「@cf/meta/llama-3-8b-instruct」生成繁體中文 3 點會議結論。
4. 全程不需額外 API 金鑰，使用 Cloudflare 原生 env.AI.run 綁定完成，輸出完整代碼。
預期成果：AI 生成免託管 GPU 的輕量級 Worker 代碼，無縫串聯語音辨識與 LLM 摘要，並給出延遲與資源消耗優化建議。
角色 07 API Gateway 維運者 · 邊緣 Rate Limiting 頻率限制
cloudflare_ratelimit

場景情境：為開放 API 端點 `/api/v2/search` 實施精確限流政策，防止惡意爬蟲發送巨量查詢拖垮後端 Elasticsearch 叢集。 

請使用 cloudflare 工具為指定 API 規劃頻率限制 (Rate Limiting) 規則：
1. 作用路徑：/api/v2/search*
2. 限流規則：以「客戶端 IP」+「X-API-Key」組合特徵識別，限制 10 秒內最高允許 50 次請求。
3. 超出限制行為：回傳 HTTP 429 Too Many Requests，並在標頭加上 Retry-After: 10 與 JSON 格式錯誤訊息。
4. 提供 Cloudflare 儀表板規則設定步驟與 Cloudflare Terraform / API 呼叫範例。
預期成果：AI 提供標準 Rate Limiting 規則定義與對應的自定義回應內容，保障後端核心運算資源免於雪崩。
角色 08 網域管理員 · DNS 批次維護與 Full Strict SSL
cloudflare_dns

場景情境：全新微服務上線，需為多個子網域配置 CNAME 記錄、開啟 Cloudflare Proxy (小橘雲) 與端到端最高等級 SSL/TLS 加密。 

請使用 cloudflare_dns 為網域「mydomain.io」進行自動化設定：
1. 建立 CNAME「api.mydomain.io」指向負載平衡器「lb.aws.mydomain.io」，開啟 Cloudflare Proxy (CDN 加速與防護)。
2. 建立 CNAME「docs.mydomain.io」指向 Notion 站點，關閉 Proxy (DNS Only)。
3. 新增 Google Workspace 郵件 MX 記錄與 SPF TXT 防偽冒記錄。
4. 檢查 SSL/TLS 加密模式，確保開啟「Full (Strict)」並強制啟用 Always Use HTTPS。
預期成果：AI 輸出完整的 DNS 批次配置 Payload，並給予 SSL/TLS 配置檢查清單，防止出現常見的重定向無窮迴圈（Error 521/522）。

4. 輸出完整的 wrangler pages 部署指令與 GitHub Actions CI/CD 配置檔。
預期成果：AI 提供 Pages 邊緣路由規範檔案、極速部署命令與 GitHub Actions YAML，實現一鍵自動化 Git-push 即部署。
角色 10 影音串流工程師 · Cloudflare Stream 防盜鏈上傳
cloudflare_stream

場景情境：線上教學平台需要上傳高品質付費教學影片，防止影片 URL 被外洩盜錄，需利用 Cloudflare Stream 簽名 URL 與網域白名單限制。 

請使用 cloudflare 工具規劃線上課程影片防盜鏈與直傳機制：
1. 配置 Cloudflare Stream Direct Creator Upload，允許前端直接將影片上傳至 Cloudflare（不經由我們自家後端伺服器）。
2. 開啟 Require Signed URLs 防盜鏈設定，只有帶有效 JWT 簽名的播放請求才能觀看。
3. 限制播放網域僅限「academy.mybrand.com」，防止被外部 iframe 嵌入盜連。
4. 撰寫 Node.js 產生 1 小時有效播放 JWT Token 的後端範例代碼。

5. 安裝外掛與設定教學

步驟一：於 Antigravity 外掛市場安裝

打開 Antigravity 外掛管理員，搜尋或直接指定合作夥伴外掛 ID 進行啟用：

antigravity-plugins-partners/plugin/cloudflare

步驟二：設定 Cloudflare API 存取憑證

前往 Cloudflare Dashboard 建立具備 Workers、D1、R2 與 DNS 編輯權限的 API Token，並於專案環境變數檔（.env）配置：

# Cloudflare API 憑證
CLOUDFLARE_API_TOKEN="your_api_token_here"
CLOUDFLARE_ACCOUNT_ID="your_account_id_here"

步驟三：搭配 Wrangler CLI 進行本機模擬

在終端機安裝 Cloudflare 官方命令列工具 wrangler，即可在本機完全模擬邊緣 Isolates 環境：

npm install -g wrangler && npx wrangler dev

6. 常見問題 (FAQ)

Cloudflare Workers 與 AWS Lambda 有何不同？

Workers 採用 Google V8 Isolates 輕量架構，無需啟動完整 Node.js 容器，因此幾乎零冷啟動延遲 (0ms)，且記憶體與 CPU 成本顯著更低。

什麼是「小橘雲 (Proxied)」狀態？

在 DNS 設定中開啟 Proxy (小橘雲)，流量會先經過 Cloudflare 全球節點進行快取加速與 WAF 防禦，並隱藏真實伺服器原始 IP。

D1 與一般關聯式資料庫差異？

D1 底層是分散式 SQLite，具有強大的讀取快取能力，非常適合讀多寫少、邊緣超低延遲查詢的 Web 應用。

R2 為何沒有出口流量費？

Cloudflare 自主建立全球光纖骨幹網路，並加入 Bandwidth Alliance，因此 R2 物件儲存徹底免除外傳流量費，僅依儲存容量與操作次數計費。
