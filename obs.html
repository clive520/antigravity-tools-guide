OBS Studio 直播錄影與 AI 智慧導播實戰指南

透過 Model Context Protocol (MCP) 與 OBS 5.x 原生 WebSocket，將強大的 AI 代理直接變身為您本機的專業影音導播台。自然語言編排多鏡頭畫中畫、自動平滑切換場景、混音側鏈壓低、自動化推流錄影，並具備即時畫布快照自檢能力！

原生 WebSocket 5.x 免裝第三方外掛 本機 127.0.0.1:4455 畫布截圖視覺自檢

1. 功能概述與架構模式

OBS Studio 過去仰賴導播員記憶複雜鍵盤熱鍵（Hotkeys）或外接實體 Stream Deck。而在 MCP 模式下，AI Agent 透過標準 stdio JSON-RPC 與本機 OBS WebSocket 伺服器對話，直接向 OBS 核心引擎發布指令：

💡 為什麼比其他桌面軟體更穩定？ 過去第三方外掛在 OBS 更新大版本時容易崩潰，但自 OBS 28 起，WebSocket 已被收編為官方核心模組（Core Module），保證向上相容，永久不會因為 OBS 升級而失效！

2. 使用者基本條件與環境需求

開始使用 OBS Studio MCP 前，請確認您的電腦設備與工作環境已滿足以下 5 大基礎條件：

1. 軟體環境條件（100% 免費開源）
  • OBS Studio 主程式：需已安裝 OBS Studio 28.0、29.x、30.x 或 31+（官方完全免費開源，無任何商業授權訂閱限制）。
  • 執行環境：本機具備 Node.js 18+（推薦使用 npx -y @royshil/obs-mcp 免安裝執行）或 Python 3.10+。
  • 內建通訊協定：確認 OBS 內建之 obs-websocket 5.0+ 已啟用。
2. 硬體規格與編碼建議
  • 記憶體 (RAM)：最低 8GB（推薦 16GB 以上，以確保多視窗螢幕擷取流暢）。
  • 硬體編碼器加速：建議具備獨立顯卡硬體編碼（NVIDIA NVENC / AMD AMF / Apple Silicon VideoToolbox / Intel QuickSync），避免 CPU 錄影負載過高。
  • 儲存空間：保留至少 10GB 以上高速 SSD 空間供本機錄影儲存。
3. AI 客戶端與 Vision 多模態支援
  • MCP 相容客戶端：Antigravity 2.0、Claude Desktop、Cursor、Windsurf 或相容用戶端。
  • Vision 視覺多模態模型（強烈推薦）：搭配 Claude 3.5 Sonnet、Gemini 2.0 Pro / Flash 或 GPT-4o，能解鎖「即時畫布快照自檢」功能，讓 AI 主動檢查鏡頭有無擋住簡報字卡。
4. 零程式門檻與本機安全防護
  • 零程式碼操作：無需精通 OBS Lua/Python 腳本或繁瑣快捷鍵，使用日常中文對話即可指揮導播台。
  • 本機通訊沙盒：WebSocket 僅監聽本機環回位址 127.0.0.1:4455，支援密碼驗證防護，完全無外網暴露漏洞。

3. 這個功能能做什麼？

OBS Studio MCP 將傳統繁複的手動導播作業，昇華為自然語言驅動的「自律型智慧導播台」：

多鏡頭與畫中畫 (PiP) 自動排版

一句話自動配置教學畫面：在 1920x1080 畫布上將簡報視窗置中放滿，右下角懸浮 400x400 圓形鏡頭，左上角自動壓印學校或公司 LOGO 浮水印。

智慧平滑場景轉場

告別手忙腳亂切錯畫面。AI 可依據演說進度，在「開場暖場倒數」、「全螢幕講師演講」、「軟體操作 Demo」與「結尾 Q&A」之間自動平滑淡入切換。

音軌平衡與側鏈壓低 (Audio Ducking)

自動偵測麥克風人聲與背景襯樂。當講者開口時，自動將 BGM 壓低至 -20dB，停頓時自然回升至 -6dB；直播破音時主動微調增益防止失真。

即時畫布快照與視覺自檢閉環

調用 obs_media_take_screenshot 擷取當前輸出畫面回傳給視覺 AI。AI 會主動檢視字體是否過小、頭像是否擋住投影片重點，並立刻自行動態位移調整！

4. 核心工具架構與 API

OBS Studio MCP 伺服器映射至 OBS WebSocket v5 原生協議，共劃分為 5 大類核心工具群組：

工具名稱 呼叫參數 (Arguments) 功能說明
obs_scenes_list 無參數 列出 OBS 當前專案內的所有場景名稱、目前主畫面場景與預覽場景。
obs_scenes_set_current_program sceneName: string 將指定的場景無縫切換至當前直播/錄影的主畫面 (Program Scene)。
obs_sources_create sceneName, sourceName, inputKind, settings 在特定場景中建立視窗擷取 (Window Capture)、相機、圖片或文字來源。
obs_scene_items_set_transform sceneName, sceneItemId, positionX, positionY, scaleX, scaleY 精確調整畫面上特定圖層的 X/Y 像素座標、長寬縮放比與旋轉角度。
obs_recording_start / stop 無參數 啟動或停止 OBS 本機高畫質 MP4/MKV 視訊錄製。
obs_streaming_start / stop 無參數 啟動或停止向 YouTube、Twitch 等平台進行 RTMP 網路即時直播。
obs_audio_set_volume sourceName: string, volumeDb: number 調節指定音軌（如麥克風、電腦桌面音訊、BGM）之音量分貝值 (dB)。
obs_audio_mute sourceName: string, muted: boolean 一鍵將特定聲音來源靜音或解除靜音（如中場休息時自動靜音麥克風）。
obs_media_take_screenshot sourceName?: string, imageFormat?: string 擷取當前畫布或特定來源的最新畫面截圖，回傳 Base64 供視覺 AI 檢驗排版。

涵蓋教學錄課、產品展示、實況遊戲、影音播客與 AI 導播視覺自檢多角實戰

10 個高階範例
角色 01 線上同步教學教師 · 自動搭建教學簡報畫中畫 (PiP)
obs_scenes_create

場景情境：需要快速為即將開始的線上課程配置標準錄課場景，包含 PowerPoint 滿版投影片，以及右下角圓形人像視訊。 

請使用 OBS MCP 替我建立一個名為「課堂教學模式」的全新場景：
1. 新增一個視窗擷取來源，鎖定視窗標題包含「PowerPoint」或「Keynote」，將畫面縮放至滿版 1920x1080 置於底層。
2. 新增我的視訊鏡頭（Video Capture Device），放置於右下角（X: 1480, Y: 680，長寬 400x360 像素），並套用 15px 圓角遮罩。
3. 將麥克風音量微調至 0dB，並確保桌面音訊開啟（音量 -10dB）。
4. 部署完畢後，將 OBS 主畫面平滑切換至此「課堂教學模式」場景。
預期產出：OBS 內即時生成結構化場景，教師視訊與簡報各就各位，無需手動拉動調整圖層尺寸。
角色 02 遊戲實況主 · 滿版遊戲源與聊天室置頂自動化
obs_scene_items_set_transform

場景情境：遊戲實況中常需在「對戰中」（遊戲全螢幕）與「中場聊天」（大鏡頭+聊天室）之間快速切換，避免手動失誤。 

請檢查我 OBS 現有的場景清單：
1. 建立「遊戲高潮對戰」場景：最底層放入遊戲擷取（Game Capture）佔滿 1080p，右上角放置半透明的 Twitch 聊天室瀏覽器元件（寬度 360px，透明度 85%）。
2. 在右上角聊天室上方新增我的視訊鏡頭（縮放為 320x240），並加上微弱的青藍色邊框光暈。
3. 將遊戲音效音量設定為 -6dB，麥克風設定為 +2dB，並將 Discord 隊友語音音量鎖定在 -3dB。
預期產出：遊戲視訊與互動懸浮元件完美融合，各音訊通道分貝值精準平衡，杜絕聲音被遊戲配樂蓋過。
角色 03 SaaS 產品經理 · 新功能 Demo 錄影與自動停止
obs_recording_start

場景情境：需要錄製一段剛好 180 秒的產品更新發布示範影片，依序切換瀏覽器畫面，並在倒數結束時自動收尾停止錄影。 

請協助我執行一段自動化 Demo 影片錄製任務：
1. 將場景切換至「產品示範」，來源鎖定 Chrome 瀏覽器的 staging 測試環境。
2. 啟動 OBS 本機錄影（調用 obs_recording_start）。
3. 提示我已開始錄影，並在第 60 秒時自動淡入標註文字「AI 智慧自動化工作流」持續 5 秒。
4. 在錄製滿 180 秒時自動調用 obs_recording_stop 停止錄影，並回傳錄製檔案之路徑與總時長。
預期產出：無縫自動起錄與收尾，完全省去錄完影片後手動剪除頭尾手忙腳亂開關 OBS 的尷尬畫面。
角色 04 跨國遠距發表會主持 · 雙人對談左右分屏 50% 排版
obs_sources_create

場景情境：跨國線上峰會進行雙人座談，需要電視台等級的專業左右對等視窗，並附帶講者職稱名牌 (Lower Third)。 

請為我搭建「國際雙人座談對談」場景：
1. 畫布底層設定為深藍科技幾何背景圖。
2. 左側 50% 放置「台北講者」視訊來源（座標 X: 40, Y: 180，寬度 880x600 像素）。
3. 右側 50% 放置「矽谷連線」視訊來源（座標 X: 1000, Y: 180，寬度 880x600 像素）。
4. 在兩位講者視窗下方各疊加一個文字橫條（Lower-Third 字卡），分別顯示講者姓名與公司職稱。
5. 完成後開啟虛擬攝影機 (Virtual Camera)，以便將輸出訊號直接串入 Zoom 會議室。
預期產出：專業電視台訪談雙分割畫面成型，虛擬相機即時啟動，Zoom 觀眾能看到頂級導播效果。
角色 05 影音播客 (Video Podcast) 製作人 · 人聲與音樂自動壓低 (Ducking)
obs_audio_set_volume

場景情境：錄製對話型 Podcast 時，背景音樂必須恰到好處，當主持人講話時背景音樂需淡化，中場空白時音樂需浮現。 

請調控我目前 OBS 的音訊混音器狀態：
1. 查詢所有音訊來源名稱與目前分貝值。
2. 將主麥克風 (Mic/Aux 1) 與訪客麥克風 (Mic/Aux 2) 的音量均衡至 -1.5dB，並確認雜訊抑制濾鏡已啟用。
3. 將背景音樂 (BGM) 音軌掛載側鏈壓縮效果，當麥克風有人聲時自動將 BGM 壓制至 -22dB；無人聲時自動回復至 -8dB。
4. 檢查音量監控指針，若任一音軌突破 0dB 產生紅燈破音，立即回報並主動降低增益 2dB。
預期產出：獲得錄音室等級的智慧側鏈動態音量平衡，完全杜絕爆音與音樂搶話干擾。
角色 06 虛擬 VTuber 實況團隊 · 綠幕去背與動態轉場切換
obs_filters_set_enabled

場景情境：VTuber 實況主使用 VTube Studio 傳輸帶綠幕或 Alpha 通道的虛擬角色，需要自動開啟色度去背 (Chroma Key) 並動態切換。 

請使用 OBS MCP 替我管理 VTuber 實況來源：
1. 為來源「VTube Studio Capture」開啟「色度去背 (Chroma Key)」濾鏡，將相似度 (Similarity) 調為 420，平滑度 (Smoothness) 調為 80，消除邊緣綠光雜色。
2. 設定快速切換場景：當我說「切換到雜談」時，平滑切換至 70% 大立繪場景；當我說「打遊戲」時，將立繪平移縮小至右下角 25%。
3. 確保切換時套用 400ms 的滑動 (Stinger) 轉場動畫。
預期產出：虛擬角色邊緣乾淨俐落無雜色溢出，並支援聲控指令即時變換立繪大小與定位。
角色 07 無障礙會議記錄員 · 雙語即時字幕浮層與手語視窗懸浮
obs_scene_items_set_transform

場景情境：大型公聽會或政府簡報直播需嚴格遵循身心障礙平權法規，視訊必須具備清晰字幕底板與手語翻譯視窗。 

請將現有簡報直播畫面重構為符合無障礙標準 (A11y)：
1. 在畫面最底端預留高度 120 像素的半透明深黑底條（RGBA 0,0,0,0.85），並接入即時語音辨識字幕來源（字體白底粗體 32pt）。
2. 在畫面右下角（字幕上方）開闢專屬手語翻譯師視窗（寬 360x270 像素），並套用高對比邊框。
3. 主講者投影片主體自動向上等比例微調縮放 90%，確保完全不被下方字幕與右側手語視窗遮擋。
預期產出：獲得完全合規的無障礙轉播配置，投影片內容與輔助字幕手語互不干擾。
角色 08 QA 自動化測試員 · 測試出錯時自動截取 OBS 畫面證據
obs_media_take_screenshot

場景情境：在執行 Playwright / Selenium 自動化回歸測試時，透過 OBS 錄影記錄全程，當測試 Assertion 失敗時自動打標快照。 

請將 OBS 作為我自動化測試的監控輔助：
1. 在測試套件啟動時，呼叫 obs_recording_start 記錄被測 Web 視窗。
2. 監聽測試結果，若發生 Assertion Error 失敗事件：
   - 立即呼叫 obs_media_take_screenshot 抓取發生錯誤瞬間的高解析全螢幕截圖。
   - 在 OBS 畫面上短暫顯示 3 秒「TEST FAILED #402」紅字警示標籤。
3. 測試完成後自動停止錄影，並將錄影檔名加上測試案例 ID（如 Test_Checkout_Fail.mp4）。
預期產出：為軟體缺陷提供最直接、無可辯駁的視訊錄影與崩潰瞬間快照證據。
角色 09 電商直播帶貨企劃 · 限時爆款搶購字卡與熱度音效切換
obs_scenes_set_current_program

場景情境：直播賣貨的高潮環節「倒數 60 秒破盤價」，需要即時切換亢奮的紅色倒數特效與搶購跑馬燈。 

請為我觸發「限時特惠促銷」導播劇本：
1. 將 OBS 主場景無縫切換至「爆款特賣專屬版型」。
2. 顯示左上角動態文字元件「限時特賣倒數中」，商品圖層拉大至中右側。
3. 播放一段歡呼與收銀機收錢的音效素材（一次性音效，音量設定為 -4dB）。
4. 在畫面下方啟動橫向滾動跑馬燈：「狂賀熱銷突破 1000 組！加碼再送專屬免運券！」。
預期產出：瞬間將直播間氛圍拉滿，主播只需專注文案叫賣，視覺與聲音特效由 AI 即時精確觸發。
角色 10 AI 智慧導播總監 · 畫布快照審查與遮擋自動修正（視覺閉環）
obs_media_take_screenshot

場景情境：在長達 2 小時的線上大會中，講者的攝影機視窗可能在不同簡報頁面中遮擋到下方的關鍵圖表數據，需由 AI 自主審視並移位。 

請扮演我的 OBS 智慧導播總監，啟動視覺自檢與自我修正閉環：
1. 調用 obs_media_take_screenshot 擷取當前直播主畫面輸出（Program Output）。
2. 用您的多模態視覺能力檢查：
   - 講者的圓形相機視窗目前是否遮擋到了簡報中的任何文字、數據圖表或程式碼區塊？
   - 畫面邊緣是否有不美觀的黑邊（Letterbox）或未對齊的空隙？
3. 若發現相機視窗遮擋文字，請自主調用 obs_scene_items_set_transform 將相機平移至畫面的對角空隙處（例如從右下角平移至左下角）。
4. 修正後再次截圖確認，向我彙報調整歷程與前後對照結論。
預期產出：神似 Blender MCP 的多模態自我修復！AI「看見」畫面瑕疵，並「主動操作」OBS API 修復圖層，實現真正意義上的無人值守智慧導播。

6. 原生 WebSocket 設定教學

OBS Studio 28.0+ 內建 WebSocket 伺服器，只需 3 分鐘即可完成本機橋接配置：

1 在 OBS 中開啟 WebSocket 伺服器
  1. 打開本機的 OBS Studio 主程式。
  2. 點擊上方功能表列的 「工具」(Tools) ➔ 「WebSocket 伺服器設定」(WebSocket Server Settings)。
  3. 勾選 「啟用 WebSocket 伺服器」(Enable WebSocket server)。
  4. 伺服器通訊埠保持預設 4455（若開啟「啟用身分驗證」，請記下或自訂一組密碼）。點擊「確定」套用。
2 在 Antigravity 或 Claude Desktop 中配置 MCP

將以下設定貼入您的 antigravity.json 或 claude_desktop_config.json 設定檔中： 

{
  "mcpServers": {
    "obs": {
      "command": "npx",
      "args": ["-y", "@royshil/obs-mcp"],
      "env": {
        "OBS_WEBSOCKET_URL": "ws://localhost:4455",
        "OBS_WEBSOCKET_PASSWORD": "your_password_here"
      }
    }
  }
}

* 若您在 OBS 設定中關閉了密碼身分驗證，則 OBS_WEBSOCKET_PASSWORD 可留空或不填。

3 重啟客戶端並測試連線

重新啟動您的 AI 用戶端，向 AI 發送第一條測試指令：
「請幫我查詢目前 OBS 中有哪些場景與音訊來源？」
若 AI 能列出場景清單，即代表本機雙向通訊已大功告成！

7. 常見問題 (FAQ)

若出現「Connection Refused (ws://localhost:4455)」錯誤怎麼辦？

請確認：(1) 本機的 OBS Studio 是否已經啟動並在運行中；(2) 在 OBS 的「工具 ➔ WebSocket 伺服器設定」中是否已勾選「啟用 WebSocket 伺服器」；(3) 檢查是否有防火牆阻擋了本機環回通訊埠 4455。

OBS 27 或更舊版本可以使用此 MCP 嗎？

OBS 27 以前版本使用的是舊版 `obs-websocket 4.x` 協議，與目前主流的 5.x 協定不相容。強烈建議直接升級至 OBS 28、29、30 或 31+，即可享受免安裝外掛的原生支援。

錄影時畫面卡頓或出現「編碼器超載 (Encoder Overload)」警示？

這是因為預設使用 CPU (x264) 進行軟體編碼導致負載過高。請在 OBS「設定 ➔ 輸出」中，將編碼器改選為硬體加速（如 NVIDIA NVENC H.264、Apple Silicon H.264 或 AMD HW），能大幅解放 CPU 資源。

如何讓 Google Meet 或 Zoom 直接吃到 OBS 排版好的畫面？

只需請 AI 執行指令或手動在 OBS 右下角點擊「啟動虛擬相機」(Start Virtual Camera)。接著打開 Google Meet、Zoom 或 Teams，將視訊鏡頭選擇為「OBS Virtual Camera」，即可完美輸出任何 AI 排版好的畫中畫！
