2. 使用者基本條件與環境需求

開始使用 Blender MCP 前，請確認您的電腦設備與工作環境已滿足以下 5 大基礎條件：

1. 軟體環境條件（100% 免費開源）
  • Blender 主程式：需已安裝 Blender 3.6 LTS、4.0、4.2 LTS 或 4.3 以上版本（官方完全免費開源，無任何訂閱限制）。
  • Python 與套件工具：本機具備 Python 3.10+，強烈推薦安裝 uv 工具（內建 uvx 指令可一鍵啟動 MCP 伺服器）。
  • 專屬外掛包：已下載並安裝 addon.py（或 mcp-for-blender.zip）。
2. 硬體配備基本建議
  • 作業系統：Windows 10/11、macOS 12+ (Apple Silicon) 或 Linux 64-bit。
  • 記憶體 (RAM)：最低 8 GB，推薦 16 GB 或 32 GB 以上，避免複雜幾何頂點導致記憶體耗盡。
  • 顯示卡 (GPU)：強烈建議配備獨立顯卡（如 NVIDIA RTX 系列支援 OptiX/CUDA，或 Apple M 系列），大幅加速 Cycles 光追算圖。
3. AI 執行端與多模態視覺
  • 支援 MCP 的客戶端：Antigravity、Claude Desktop、Cursor 或 Claude Code。
  • 多模態視覺模型（強烈建議）：搭配具備視覺辨識的模型（如 Claude 3.5 Sonnet、Gemini 2.0 Pro、GPT-4o），AI 才能真正「看懂視口截圖」並自動修正位置與光影。
4. 技能門檻與存檔意識
  • 新手友善零代碼：使用者無需記憶複雜快捷鍵、無需會寫 Python 代碼，只要用自然語言表達需求即可。
  • 本機連線許可：本機防火牆需放行 127.0.0.1:9876 本地通訊埠。
  • 備份習慣：由於 AI 執行腳本不一定能完全觸發 Ctrl+Z 歷史堆疊，建議操作前養成 Ctrl+S 存檔或另存副本習慣。

3. 這個功能能做什麼？

Blender MCP 整合套件賦予 Antigravity 4 大三維數位內容創作維度：

自然語言 3D 幾何與程序化建模

自動生成多邊形網格（Mesh）、布林運算（Boolean）、陣列複製、細分曲面與貝茲曲線擠出，秒速建立低面數與高精度 3D 幾何。

PBR 物理著色器與材質節點樹生成

自動配置 Principled BSDF 著色器節點，精準調配金屬度 (Metallic)、粗糙度 (Roughness)、次表面散射與發光 (Emission) 特效。

電影級三點打光與 HDRI 環境配置

自動擺設主光 (Key Light)、補光 (Fill Light) 與邊緣輪廓光 (Rim Light)，設定色溫 (Kelvin) 與載入無縫天空穹頂環境貼圖。

AI 視口截圖審查與雙引擎算圖輸出

多模態 AI 透過 get_viewport_screenshot 親眼審閱構圖視角，自動調整景深相機，並一鍵以 Eevee / Cycles 匯出 4K 靜態圖或動畫。

6. 安裝外掛與設定教學

步驟一：安裝 Blender Companion Add-on 外掛

自開源倉庫下載 mcp-for-blender 的外掛檔案（例如 addon.py），打開 Blender 依序點擊：

Edit > Preferences > Add-ons > Install... (選取 addon.py 並勾選啟用)

步驟二：在 3D 視圖側邊欄開啟 MCP Server

回到 Blender 3D Viewport，按下鍵盤快速鍵 N 展開右側面板，找到「Blender MCP」標籤，點擊 「Start MCP Server」。畫面顯示綠燈 Listening on 127.0.0.1:9876 即表示就緒。

步驟三：在 Antigravity / Claude 設定檔配置

在您的 MCP Client 設定檔中（例如 Claude Desktop 的 claude_desktop_config.json），加入以下啟動指令：

{
"mcpServers": {
"blender": {

7. 常見問題 (FAQ)

若出現「Connection Refused (127.0.0.1:9876)」怎麼辦？

通常是因為 Blender 內部的 Add-on 尚未點擊啟動，或是 Blender 意外關閉。請確認 Blender 保持開啟，並在 N-Panel 確認 MCP 狀態顯示為綠色 Running。

AI 做出的模型不滿意，可以 Ctrl+Z 復原嗎？

部分 Python 腳本不會自動寫入 Blender 的 Undo Stack。建議您直接對 AI 說「復原剛剛的修改」或「刪除剛剛建立的甜甜圈」，AI 能精確按名稱清理，或者在大型變動前手動按下 Ctrl+S 存檔。

沒有獨立顯示卡（只有內顯）能用嗎？

完全可以！Blender 的即時 Eevee 渲染引擎與基礎建模對硬體負擔很低，一般筆電內顯也能流暢操作。僅有在開啟 Cycles 複雜物理光線追蹤時才強烈推薦獨立顯卡。

是否支援最新的 Blender 4.2 / 4.3 擴充套件系統？

支援。Blender 4.2 引入了全新 Extensions 架構，但依然相容傳統 Add-on 安裝方式，只要將外掛檔案複製進 addons 目錄即可正常常駐。
