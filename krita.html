Krita 數位插畫與畫布 AI 視覺自檢實戰指南

透過 Model Context Protocol (MCP) 與 Krita 原生 Python 外掛，解鎖極具突破性的「畫布生成 ➔ 視覺快照反饋 ➔ 自主迭代微調」閉環。AI 代理能直接在 Krita 建立圖層結構、設定 Multiply/Overlay 混合模式、繪製色塊並導出高解析度作品！

原生 Python 外掛 圖層與混合模式 畫布快照視覺自檢 本機 127.0.0.1:8080

2. 使用者基本條件與環境需求

1. 軟體環境條件（100% 免費開源）
  • Krita 主程式：需已安裝 Krita 5.1、5.2 或最新版本（官方免費開源，無任何訂閱門檻）。
  • Python 與外掛：本機具備 Python 3.10+，並在 Krita 內啟用 krita-mcp 外掛。
2. 硬體規格建議
  • 記憶體 (RAM)：最低 8GB（高解析 300DPI 多圖層畫布推薦 16GB 以上）。
  • 顯示卡：支援 OpenGL 3.2+ 硬體加速，畫布縮放旋轉絲滑順暢。
3. AI 視覺多模態支援
  • 強烈推薦具備 Vision 之模型：Claude 3.5 Sonnet、Gemini 2.0 Pro / Flash 或 GPT-4o，能自主檢查畫布光影並進行迭代修復。
4. 零繪畫基礎與沙盒通訊
  • 零繪畫門檻：使用者完全無需繪畫經驗，口述氛圍與構圖，由 AI 指揮圖層與色塊。
  • 本機通訊安全：僅監聽本機 127.0.0.1:8080，畫布素材絕不外流。

3. 這個功能能做什麼？

智慧規格化畫布建立

自動建立 3840x2160 (4K 橫幅)、1080x1920 (手機桌布) 或 300DPI 印刷畫布，預先設定好色彩空間與背景底色。

專業分層架構與混合模式

自動建立「底稿線條」、「色彩平塗」、「正片疊底陰影 (Multiply)」與「疊加高光 (Overlay)」，圖層邏輯井然有序。

幾何筆刷與色塊鋪排

依據調色盤在指定圖層繪製平滑漸層、色塊構圖與形狀，為後續人工精修或概念設計提供極致底稿。

畫布快照視覺自檢閉環

調用 krita_get_canvas_screenshot 獲取畫布畫面，視覺 AI 自主審查明暗對比，並自主修復色彩飽和度。

4. 核心工具架構與 API

工具名稱 呼叫參數 (Arguments) 功能說明
krita_create_document width, height, dpi, color_model 建立指定解析度與色彩規格的新插畫文件。
krita_layer_management action, layer_name, blending_mode, opacity 新建、刪除、命名圖層，設定圖層不透明度與混合模式。
krita_draw_stroke_shape layer_name, shape_type, points, color_hex 在特定圖層上繪製幾何路徑、色塊或漸層填充。
krita_get_canvas_screenshot include_background?: boolean 擷取當前畫布 PNG 快照，以 Base64 回傳供視覺模型審核畫面。
krita_export_image file_path, format: "kra" | "png" | "psd" 將專案完整匯出為 Krita 原始工程檔或通用圖檔。

5. 10 大跨角色實戰 Prompt

涵蓋概念原畫、角色線稿、像素美術、水彩插畫與 AI 畫布視覺自檢多角實戰

10 個高階範例
角色 01 概念原畫師 · 賽博朋克夜雨街景色彩基調搭建
krita_create_document

場景情境：需要快速搭建一幅 3840x2160 的賽博朋克概念氛圍底稿，建立標準色調並鋪設基礎色塊。 

請使用 Krita MCP 為我建立「賽博朋克夜景」概念底稿：
1. 建立 3840x2160、300DPI、RGB 8-bit 的畫布，背景填滿深青色 (#050b14)。
2. 自動建立以下標準圖層結構：
   - `BG_Skyline`（遠景天際線色塊）
   - `Mid_Buildings`（中景大樓幾何剪影）
   - `Neon_Glow`（混合模式設為 Color Dodge 或 Screen，繪製粉紅 #ff007f 與青綠 #00ffff 霓虹倒影）
   - `Rain_Overlay`（半透明細雨質感）
3. 建立完成後調用 krita_get_canvas_screenshot 回傳初始氛圍快照。
角色 02 動漫角色線稿師 · 標準賽璐珞三層上色體系
krita_layer_management

場景情境：為角色繪製建立嚴謹的分層，包含線稿、平塗固有色、一影與二影。 

請在現有畫布中配置標準賽璐珞 (Cel Shading) 分層系統：
1. 建立圖層組 `Character_Group`。
2. 頂層建立 `Line_Art`（混合模式 Normal，不透明度 100%）。
3. 中層建立 `Shadow_Multiply`（混合模式設為 Multiply，不透明度 70%，預設填入淡紫灰色 #a594b5）。
4. 底層建立 `Base_Color`（鎖定透明度 Alpha Lock 開啟）。
5. 確保線稿層置頂不受下層陰影塗抹污染。
角色 03 遊戲 2D 像素美術 · 64x64 復古地牢寶箱畫布
krita_create_document

場景情境：建立微型像素網格，關閉抗鋸齒並限制調色盤為 16 色。

請建立像素繪圖專用畫布：
1. 建立 64x64 像素、72DPI 畫布，關閉畫布縮放抗鋸齒（Nearest Neighbor 插值）。
2. 在頂層開啟 1 像素對齊網格 (Grid 1px)。
3. 使用經典 GameBoy 4 色階調色盤 (#0f380f, #306230, #8bac0f, #9bbc0f) 繪製寶箱幾何剪影。
角色 04 水彩風格插畫家 · 紙張紋理疊加與邊緣暈染
krita_layer_management 
請為我搭建數位水彩專用畫布：
1. 底層填滿米白色冷壓水彩紙色調 (#fbf8f1)。
2. 最頂層建立 `Paper_Texture` 圖層，混合模式設定為 Overlay，不透明度 45%。
3. 中間建立 `Wet_Watercolor` 圖層，筆刷選用平滑邊緣漸層與擴散暈染效果。
角色 05 童書繪本繪師 · 森林背景大色塊構圖
krita_draw_stroke_shape 
請繪製童書暖調森林場景：
1. 建立 2048x1536 畫布。
2. 在草皮圖層以嫩綠色 (#88d49e) 與鵝黃色 (#f6f740) 繪製柔和波浪起伏山丘。
3. 在畫面左側繪製三棵圓頭童話巨木，右上方保留 40% 空白區域供後續排入繪本文案。
角色 06 UI 圖示設計師 · 300DPI 向量路徑圖標繪製
krita_create_document 
請建立 8 款 App 圖示繪製模板：
1. 建立 1024x1024 畫布，300DPI，透明背景。
2. 建立輔助圓形遮罩（直徑 800px），並施加半徑 40px 圓角。
3. 匯出為無損 PNG 與 Krita 原始圖層檔。
角色 07 啞光背景 (Matte Painter) · 大氣透視深度霧效
krita_layer_management 
請建立大氣透視景深圖層：
1. 建立「遠景雪山」圖層，填色降低飽和度與對比度（偏向大氣灰藍）。
2. 在中景與遠景之間插入「Fog_Atmosphere」圖層，填入淡白藍色垂直線性漸層，不透明度 35%。
3. 檢查三層圖層之深度分離度。
角色 08 刺青紋身設計師 · 曼陀羅對稱幾何圖騰
krita_draw_stroke_shape 
請配置對稱幾何圖騰環境：
1. 開啟 8 軸多重鏡像 (Multibrush Symmetry) 模式。
2. 筆刷鎖定純黑 (#000000)，筆觸平滑度 (Stabilizer) 設定為最高值 80。
3. 繪製由中心向外綻放的幾何曼陀羅花紋圖騰。
角色 09 材質貼圖師 · 2048x2048 無縫四方連續磚牆紋理
krita_export_image 
請配置無縫平鋪 (Wrap-around) 紋理模式：
1. 建立 2048x2048 畫布，開啟 Krita 快捷平鋪模式 (Wrap-around Mode, 快速鍵 W)。
2. 繪製磚塊排列與水泥縫隙，確保邊緣接縫無縫循環銜接。
3. 匯出為無壓縮的 32-bit PNG 貼圖檔案。
角色 10 AI 藝術總監 · 畫布快照光影審查與色調自我迭代（視覺閉環）
krita_get_canvas_screenshot 
請擔任我的插畫藝術指導，啟動視覺反饋自檢閉環：
1. 呼叫 krita_get_canvas_screenshot 擷取當前畫布完整快照。
2. 用您的視覺感知檢查：
   - 主體角色面部受光是否過暗？明暗對比 (Contrast) 是否足夠突出焦點？
   - 背景色是否喧賓奪主搶走視覺中心？
3. 若對比不足，請自主在頂層建立 Curves 或 Levels 調整層，並將陰影層不透明度降低 15%。
4. 修正後再次截圖確認，向我彙報調整前後差異。

6. 安裝與設定教學

1 在 Krita 中啟用 Python 外掛

自 krita.org 安裝 Krita。在「設定 ➔ 配置 Krita ➔ Python 外掛程式管理員」中勾選啟用 krita-mcp 外掛並重啟。

2 配置 Antigravity / Claude MCP 設定檔 
{
  "mcpServers": {
    "krita": {
      "command": "uvx",
      "args": ["krita-mcp"],
      "env": {
        "KRITA_PORT": "8080"
      }
    }
  }
}

7. 常見問題 (FAQ)

AI 會取代繪師的手繪手感與壓感筆刷嗎？

不會！Krita MCP 的定位是「強大的 AI 助手與上色底稿排版員」。它負責繁瑣的畫布建立、大色塊鋪排與氛圍調整，藝術家依然可以在手繪板上用靈活的手感進行最後的筆觸精修。

匯出的檔案是否能用 Photoshop 開啟？

可以！Krita 原生支援匯出包含完整圖層與混合模式之 .psd 檔案，可在 Photoshop 或 Clip Studio Paint 中無縫開啟繼續創作。
