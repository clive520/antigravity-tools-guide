2. 使用者基本條件與環境需求

1. 軟體環境條件
  • Photoshop 版本：需已安裝 Adobe Photoshop 2021 至 2024 / 2025（Windows 或 macOS 原生版）。
  • 執行環境：本機具備 Node.js 18+ 或 Python 3.10+。
2. 硬體規格建議
  • 記憶體 (RAM)：建議 16GB+ RAM（多圖層海報推薦 32GB）。
  • 顯示卡：支援 GPU 影像加速，加快大圖渲染導出。
3. AI 多模態模型
  • 搭配 Claude 3.5 Sonnet 或 Gemini 2.0，能檢視修圖前後對比並微調色彩平衡。
4. 安全與技能門檻
  • 零工具快捷鍵門檻：口述調色與排版意圖即可生成。
  • 商業資產安全：本機沙盒運行，素材絕不外傳雲端。

3. 這個功能能做什麼？

PSD 分層結構與遮罩自動化

自動為專案建立規範化的圖層群組（背景層、主體層、調色層、文字排版層），並精準附帶圖層遮罩。

商業級無損曲線與色相調整

自動掛載曲線 (Curves)、色階 (Levels) 與色彩平衡 (Color Balance) 調整層，實現完全可逆的無損調色。

全通路畫板 (Artboards) 批次切圖

將一份主視覺自動延伸建立 1:1 IG 貼文、9:16 限時動態與 16:9 廣告橫幅，一鍵批次導出高壓縮比 WebP/PNG。

印前製版 CMYK 與圖層規範自檢

檢查 RGB 轉 CMYK 是否超限、自動加上 3mm 出血線，並將混亂的圖層重新規範命名打包。

4. 核心工具架構與 API

工具名稱 呼叫參數 功能說明
ps_open_create_document file_path?, width?, height?, mode: "RGB"|"CMYK" 打開現有 PSD 文件或建立全新指定規格畫布。
ps_add_layer_mask layer_name, mask_type: "reveal"|"hide" 為指定圖層新增透明遮罩並鎖定邊界。
ps_apply_adjustment_filter filter_type: "curves"|"levels"|"hue_sat", params 掛載無損調色調整層或套用濾鏡效果。
ps_get_document_layers 無參數 檢索 PSD 內所有圖層階層樹、可見度與混合模式。
ps_batch_export_assets artboards_or_layers, format: "png"|"jpg"|"webp" 批次將特定畫板或圖層匯出為多尺寸網頁圖檔。

5. 10 大跨角色實戰 Prompt

涵蓋電商修圖、社群橫幅、電影海報、UI 重構、攝影調色與印前製版多角實戰

10 個高階範例
角色 01 電商產品精修師 · 去背投影與金屬高光對比度增強
ps_apply_adjustment_filter 
請為當前手錶產品圖進行商業精修處理：
1. 為手錶主體建立精確主體遮罩（羽化半徑 0.5px）。
2. 在手錶下方建立柔和接觸陰影層（填入深灰 #1a1a1a，高斯模糊 12px，不透明度 60%）。
3. 針對金屬錶帶掛載曲線調整層，提升亮部反光並壓暗深色陰影以增加金屬質感。
4. 儲存為分層 PSD 並導出 2000x2000 白底 JPG。
角色 02 社群廣告設計師 · 1080x1080 正方形爆款促銷貼文
ps_open_create_document 
請建立 Instagram 廣告貼文版型：
1. 建立 1080x1080 像素、72DPI、sRGB 畫布。
2. 建立四個群組：`Background`、`Product_Hero`、`Badge_Discount`、`Typography`。
3. 在左上角添加醒目的黃色限時折價氣泡，右側放置去背主產品。
角色 03 電影海報設計師 · 青橙色調 (Teal & Orange) 史詩合成
ps_apply_adjustment_filter 
請為海報專案套用好萊塢電影青橙調色：
1. 掛載「色彩平衡」調整層：陰影加青藍色 (+15 Cyan, +10 Blue)，高光加暖橙色 (+20 Red, +15 Yellow)。
2. 在頂層掛載柔焦發光圖層（Color Dodge 混合模式，不透明度 30%）。
角色 04 UI 設計師 · 3x Retina 高清介面圖層組自動重構
ps_get_document_layers 
請重構現有 App UI 介面圖層：
1. 建立 1170x2532 畫布（iPhone 14 Pro 規格）。
2. 將所有按鈕轉換為智慧型物件 (Smart Objects)。
3. 規範命名所有圖層群組（`NavBar`、`Cards_List`、`TabBar`）。
角色 05 婚紗攝影師 · 柔焦漫射 (Orton Effect) 與膚色溫潤調教
ps_apply_adjustment_filter 
請為婚紗人像套用經典 Orton Effect：
1. 複製可見圖層並套用高斯模糊 (半徑 25px)。
2. 混合模式設為 Screen，透明度 40%。
3. 疊加溫暖膚色曲線調整層，提升暗部細節。
角色 06 多通路視覺美編 · 畫板 (Artboards) 批次匯出三種規格
ps_batch_export_assets 
請將主視覺畫板延伸生成三個尺寸：
1. 畫板 A: 1200x628 (Facebook 橫幅)
2. 畫板 B: 1080x1920 (TikTok 直式)
3. 畫板 C: 800x800 (蝦皮電商)
4. 一鍵批次匯出為 85% 品質 WebP 格式。
角色 07 服裝設計師 · 精確遮罩換色快速預覽 5 種色票
ps_add_layer_mask 
為模特兒身上的洋裝建立色相調整群組：
1. 建立衣物邊緣遮罩。
2. 掛載色相/飽和度調整層，快速預覽經典黑、海軍藍、翡翠綠、米白與勃根地紅。
角色 08 印前製版員 · CMYK 色彩模式轉換與 3mm 出血線
ps_open_create_document 
請將傳單專案進行印刷合規處理：
1. 色彩模式轉換為 CMYK (Japan Color 2001 Coated 色彩設定檔)。
2. 擴展畫布四周 3mm 印刷出血位。
3. 確保黑色小字為純單色黑 (K 100%) 防止套印不準。
角色 09 文字排版主美 · 斜角浮雕與立體金屬漸層樣式
ps_apply_adjustment_filter 
為大標題文字套用立體圖層樣式：
1. 施加斜角與浮雕 (Bevel & Emboss, 深度 200%, 尺寸 8px)。
2. 疊加金黃色金屬漸層與 2px 外部金色描邊。
角色 10 AI 圖層稽核總監 · 亂命名圖層智慧歸類與分組打包（圖層自檢）
ps_get_document_layers 
啟動 PSD 專案圖層衛生大掃除：
1. 掃描所有名為「圖層 1」、「圖層 2 拷貝」的未命名圖層。
2. 依據內容自動重命名為具描述性之語意標籤。
3. 刪除所有全透明或被完全遮擋的隱藏無用圖層，並將圖層樹整理為 4 個主群組。

6. 安裝與設定教學

1 確保本機 Photoshop 開啟遠端連線

在 Photoshop 的「偏好設定 ➔ 外掛程式」(Plugins) 中，勾選「啟用遠端連線」(Enable Remote Connections)，並設定密碼。

2 配置 Antigravity / Claude 設定檔 
{
  "mcpServers": {
    "photoshop": {
      "command": "npx",
      "args": ["-y", "photoshop-mcp"],
      "env": {
        "PHOTOSHOP_PASSWORD": "your_ps_password"
      }
    }
  }
}

7. 常見問題 (FAQ)

智慧型物件 (Smart Objects) 的向量無損特性會被破壞嗎？

不會！Photoshop MCP 在執行旋轉、縮放與透視變形時，優先保留智慧物件原始圖層，絕不破壞性點陣化，隨時可雙擊回溯向量原稿。
